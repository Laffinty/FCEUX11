一、MMC5 扩展芯片
----------------
来源：goroh / mmc5-e.txt (翻译：Sgt. Bowhack)

音频寄存器：
  $5000/$5004：ch1/ch2 方波控制
    bit 7-6=占空比 (0=87.5%, 1=75%, 2=50%, 3=25%)
    bit 5=波形保持 (1=循环)
    bit 4=包络选择 (0=变化, 1=固定)
    bit 3-0=e=0 时=播放速率；e=1 时=输出音量
  $5002/$5006：频率低 8 位
  $5003/$5007：频率高 3 位 + 长度计数器 5 位
  $5010：ch3 合成语音通道开关 (bit 0)
  $5011：ch4 波形大小 (8-bit)
  $5015：通道输出使能 (bit 0=ch1, bit 1=ch2)

内存映射寄存器：
  $5100：PRG 页大小 (0=32K, 1=16K, 2/3=8K)
  $5101：CHR 页大小 (0=8K, 1=4K, 2=2K, 3=1K)
  $5102/$5103：BBR-RAM 写保护 (必须写 2/1 才允许写入)
  $5104：图形模式 (0=Split, 1=Split+ExGrafix, 2=ExRAM, 3=ExRAM+写保护)
  $5105：NameTable 设置 (每 2 bit 选择 4 个 1K VRAM 区域来源)
  $5106/$5107：Fill Mode (填充字符/调色板)
  $5113：$6000-$7FFF RAM 页
  $5114-$5117：PRG 换页 (依 $5100 设置的大小)
  $5120-$512B：CHR 换页 (Mode A: $5120-$5127; Mode B: $5128-$512B)
  $5200：Split Mode 控制 (使能、边界侧、边界字符数)
  $5201/$5202：Split Mode 垂直滚动/CHR 页指定
  $5203：扫描线中断触发点
  $5204：IRQ 使能/状态 (bit 7)
  $5205/$5206：硬件 8×8 乘法器 ($5205 × $5206 = 结果)

$5C00-$5FBF 扩展 VRAM：
  - ExGrafix 模式：每字符指定调色板 (2 bit) + 背景 CHR 页 (6 bit)
  - Split 模式：作为扩展 name table
  - ExRAM 模式：作为扩展 RAM


二、VRCVI (VRC6) 扩展音频芯片
------------------------------
来源：Kevin Horton / vrcvi.txt

芯片信息：48-pin DIP，用于 CV3j、Madara 等 Konami 游戏（仅 Famicom）。
音频输出通过 6-bit R2R 电阻网络。

寄存器（仅音频部分）：
  Pulse 通道 1 ($9000-$9002)：
    $9000：GDDDVVVV
      D=占空比 (000=6.25% ... 111=50%)
      V=音量 (0000=静音 ... 1111=最大)
      G=Gate (0=正常, 1=数字/直接采样模式)
    $9002：频率低 8 位
    $9003：X---FFFF (X=通道使能, F=频率高 4 位)

  Pulse 通道 2 ($A000-$A002)：与通道 1 相同。

  Sawtooth 通道 ($B000-$B002)：
    $B000：--PPPPPP (P=相位累加器输入)
    $B001：频率低 8 位
    $B002：X---FFFF (X=通道使能)

工作原理：
  - Pulse：12-bit 分频器 → 占空比发生器(÷16) → 4 AND 门阵列 → 4-bit 输出
  - Sawtooth：12-bit 分频器 → 相位累加器(每 7 周期加一次 P 值，÷14) → 5-bit 输出
  - 最终 2 个 pulse (4-bit) 和 sawtooth (5-bit) 相加，经 6-bit R2R DAC 输出。

频率公式：
  Pulse：    Fout = 1789772.7272 / ((freq+1) × 16)
  Sawtooth： Fout = 1789772.7272 / ((freq+1) × 14)

注意：部分卡带 A0/A1 线接反，若音乐异常可尝试交换寄存器对 (xxx1 与 xxx2)。


三、VRCVII (VRC7) 扩展音频芯片
-------------------------------
来源：Kevin Horton / vrcvii.txt

芯片信息：48-pin DIP，用于 Lagrange Point 等 Konami 游戏（仅 Famicom）。
采用 FM 合成（类似 Adlib OPL2），音频经小型混合模块输出到 Famicom。

寄存器（仅音频部分）：
  $9010：索引寄存器（选择内部寄存器号）
  $9030：数据寄存器（写入索引指向的寄存器）

声音寄存器：
  $00-$07：自定义乐器参数（与 OPL2 功能相同）
    00/01：Modulator/Carrier  tremolo/vibrato/sustain/KSR/倍频
    02：Key Scale Level / Output Level
    03：波形选择 + Feedback
    04/05：Attack / Decay
    06/07：Sustain / Release
  $10-$15：频率低 8 位
  $20-$25：???tooof (t=触发, o=八度, f=频率高位)
  $30-$35：iiii vvvv (i=乐器号, v=音量)
    乐器 $01-$0F 为固定音色；$00 为可编程自定义乐器。

频率公式：
           49722 × freqval
  F = ---------------------
       2^(19 - octave)

  octave = 0..7；freqval = 频率寄存器值。

固定乐器参数表（寄存器 $00-$07，不完全精确）：
  Inst 1: 05 03 10 06 74 A1 13 F4
  Inst 2: 05 01 16 00 F9 A2 15 F5
  ... (详见原文档)

注意：仅有两种波形：正弦波和整流正弦波（仅正半周期）。


四、SMB2j Mapper #50
--------------------
来源：The Mad Dumper / smb2j.txt

硬件：6 个 TTL 芯片 + 8K VRAM + 128K PRG ROM。
数据线 D3/D6 以及地址线 A1/A3 有交换（ROM 镜像已修正）。

寄存器（位于 $4000-$5FFF，地址译码奇特）：
  地址模式：010x xxxQ x01x xxxx
  Q=0：ROM 页寄存器 (4 bit，映射到 C000-DFFF)
  Q=1：IRQ 定时器使能 (bit 0)

IRQ 定时器：
  - 由 4020 二进制纹波计数器构成。
  - 4096 个 M2 周期后拉低 /IRQ（约 36 扫描线）。
  - 用于顶部分数栏的屏幕分割。

ROM 内存映射（8K 页）：
  $6000-$7FFF：固定 bank $0F
  $8000-$9FFF：固定 bank $08
  $A000-$BFFF：固定 bank $09
  $C000-$DFFF：可切换 bank（bit 顺序 DACB）
  $E000-$FFFF：固定 bank $0B

I. MMC5 Expansion Chip
----------------------
Source: goroh / mmc5-e.txt (translated by Sgt. Bowhack)

Audio registers:
  $5000/$5004: ch1/ch2 square control
    bits 7-6 = duty cycle (0=87.5%, 1=75%, 2=50%, 3=25%)
    bit 5 = waveform hold (1=loop)
    bit 4 = envelope select (0=variable, 1=fixed)
    bits 3-0 = playback rate if e=0; output volume if e=1
  $5002/$5006: frequency low 8 bits
  $5003/$5007: frequency high 3 bits + length counter 5 bits
  $5010: ch3 synth voice on/off (bit 0)
  $5011: ch4 wave size (8-bit)
  $5015: channel output enable (bit 0=ch1, bit 1=ch2)

Memory mapping registers:
  $5100: PRG page size (0=32K, 1=16K, 2/3=8K)
  $5101: CHR page size (0=8K, 1=4K, 2=2K, 3=1K)
  $5102/$5103: BBR-RAM write protect (must write 2/1 to allow writes)
  $5104: graphics mode (0=Split, 1=Split+ExGrafix, 2=ExRAM, 3=ExRAM+WP)
  $5105: name table select (2 bits per 1K region)
  $5106/$5107: fill mode char/palette
  $5113: $6000-$7FFF RAM page
  $5114-$5117: PRG bank switch (size depends on $5100)
  $5120-$512B: CHR bank switch (Mode A: $5120-$5127; Mode B: $5128-$512B)
  $5200: split mode control (enable, side, boundary chars)
  $5201/$5202: split mode vertical scroll / CHR page
  $5203: scanline IRQ trigger point
  $5204: IRQ enable/status (bit 7)
  $5205/$5206: hardware 8×8 multiplier ($5205 × $5206 = result)

$5C00-$5FBF extended VRAM:
  - ExGrafix mode: per-tile palette (2 bits) + background CHR page (6 bits)
  - Split mode: extended name table
  - ExRAM mode: extension RAM


II. VRCVI (VRC6) Expansion Audio Chip
-------------------------------------
Source: Kevin Horton / vrcvi.txt

Chip info: 48-pin DIP, used in Konami games like CV3j and Madara (Famicom only).
Audio output via 6-bit R2R resistor ladder.

Registers (audio only):
  Pulse channel 1 ($9000-$9002):
    $9000: GDDDVVVV
      D = duty cycle (000=6.25% ... 111=50%)
      V = volume (0000=silent ... 1111=max)
      G = Gate (0=normal, 1=digitized/direct sample mode)
    $9002: frequency low 8 bits
    $9003: X---FFFF (X=channel enable, F=frequency high 4 bits)

  Pulse channel 2 ($A000-$A002): identical to channel 1.

  Sawtooth channel ($B000-$B002):
    $B000: --PPPPPP (P=phase accumulator input)
    $B001: frequency low 8 bits
    $B002: X---FFFF (X=channel enable)

Operation:
  - Pulse: 12-bit divider → duty cycle generator (÷16) → 4 AND gate array → 4-bit output
  - Sawtooth: 12-bit divider → phase accumulator (add P every 7 cycles, ÷14) → 5-bit output
  - Final mix: two pulses (4-bit) + sawtooth (5-bit) added together → 6-bit R2R DAC.

Frequency formulas:
  Pulse:    Fout = 1789772.7272 / ((freq+1) × 16)
  Sawtooth: Fout = 1789772.7272 / ((freq+1) × 14)

Note: some carts have A0/A1 lines swapped; if music sounds wrong, swap register pairs (xxx1 and xxx2).


III. VRCVII (VRC7) Expansion Audio Chip
---------------------------------------
Source: Kevin Horton / vrcvii.txt

Chip info: 48-pin DIP, used in Lagrange Point (Famicom only).
FM synthesis (Adlib OPL2-like), audio output through small hybrid module.

Registers (audio only):
  $9010: index register (select internal register number)
  $9030: data register (write to register pointed by index)

Sound registers:
  $00-$07: custom instrument parameters (functionally identical to OPL2)
    00/01: Modulator/Carrier tremolo/vibrato/sustain/KSR/multiplier
    02: Key Scale Level / Output Level
    03: waveform select + feedback
    04/05: Attack / Decay
    06/07: Sustain / Release
  $10-$15: frequency low 8 bits
  $20-$25: ???tooof (t=trigger, o=octave, f=frequency high bit)
  $30-$35: iiii vvvv (i=instrument, v=volume)
    instruments $01-$0F fixed; $00 programmable custom.

Frequency formula:
           49722 × freqval
  F = ---------------------
       2^(19 - octave)

  octave = 0..7; freqval = frequency register value.

Fixed instrument parameter table (registers $00-$07, not 100% exact):
  Inst 1: 05 03 10 06 74 A1 13 F4
  Inst 2: 05 01 16 00 F9 A2 15 F5
  ... (see original doc for full table)

Note: only two waveforms available: sine and rectified sine (positive half only).


IV. SMB2j Mapper #50
--------------------
Source: The Mad Dumper / smb2j.txt

Hardware: 6 TTL chips + 8K VRAM + 128K PRG ROM.
Data lines D3/D6 and address lines A1/A3 are swapped (fixed in released ROM).

Registers (at $4000-$5FFF, unusual decode):
  Address pattern: 010x xxxQ x01x xxxx
  Q=0: ROM page register (4 bits, maps to C000-DFFF)
  Q=1: IRQ timer enable (bit 0)

IRQ timer:
  - 4020 binary ripple counter.
  - /IRQ asserted after 4096 M2 cycles (~36 scanlines).
  - Used for top score bar screen split.

ROM memory map (8K banks):
  $6000-$7FFF: fixed bank $0F
  $8000-$9FFF: fixed bank $08
  $A000-$BFFF: fixed bank $09
  $C000-$DFFF: switchable bank (bit order DACB)
  $E000-$FFFF: fixed bank $0B
