# FCEUX11 v0.3.12 内存布局与缓存优化说明

## 范围

本子版本执行 `docs/v0.3.x_Construction_Plan_v3.md` §5 v0.3.12：

> - 引入 `std::hardware_destructive_interference_size` 标注 mapper 寄存器组。
> - PRG/CHR 切换表预取。

## 设计选择

由于 NES 卡带读取存在 **open-bus** 语义（`CartBROB` 在 `Page[A>>11]` 为 null 时返回总线最后值 `X.DB`），直接实现一个 32 KiB 的 PRG 字节预取表需要在每次 bank switch、PRG-RAM 写、open-bus 变化时同步，容易破坏字节级一致性。因此 v0.3.12 采用**保守方案**：

1. 用 64 字节对齐所有热路径数组（`Page`、`VPage`、`ARead`/`BWrite`、mask 表等）。
2. 在 `CartBR` / `CartBROB` / `FFCEUX_PPURead_Default` 中加入 `_mm_prefetch` 软件预取提示。
3. 用 `FCEUX11_MAPPER_HOT` 宏标注热点 mapper 的寄存器组。

这样可以在不改变执行语义、不引入派生表维护路径的前提下完成“内存布局优化”目标。

## 对齐的数组清单

### `src/cart.cpp` / `src/cart.h`

- `Page[32]`, `VPage[8]`, `VPageG[8]`
- `MMC5SPRVPage[8]`, `MMC5BGVPage[8]`
- `PRGptr[32]`, `CHRptr[32]`
- `PRGsize[32]`, `CHRsize[32]`
- `PRGmask2/4/8/16/32[32]`, `CHRmask1/2/4/8[32]`
- `PRGram[32]`, `CHRram[32]`, `PRGIsRAM[32]`

### `src/fceu.cpp` / `src/fceu.h`

- `ARead[0x10000]`
- `BWrite[0x10000]`

### `src/x6502.cpp` / `src/ops_table.inc`

- `CycTable[256]`
- `opsize[256]`, `optype[256]`, `opwrite[256]`
- `x6502_dispatch`（256 个函数指针的 `std::array`）

## Mapper 寄存器组标注

`FCEUX11_MAPPER_HOT` 宏在 `src/utils/cache.h` 中定义，等价于 `alignas(64)`。已标注文件：

- `src/boards/mmc1.cpp`: `DRegs[4]`
- `src/boards/mmc3.cpp`: `DRegBuf[8]`, `EXPREGS[8]`
- `src/boards/mmc5.cpp`: `PRGBanks`, `CHRBanksA`, `CHRBanksB`, `WRAMMaskEnable`, `mul`, `MMC5ROMWrProtect`, `MMC5MemIn`
- `src/boards/vrc2and4.cpp`: `prgreg[2]`, `chrreg[8]`, `chrhi[8]`
- `src/boards/vrc6.cpp`: `prg[2]`, `chr[8]`
- `src/boards/vrc7.cpp`: `preg[3]`, `creg[8]`
- `src/boards/datalatch.cpp`: `latche`, `latcheinit`, `addrreg0/1`
- `src/boards/addrlatch.cpp`: `latche`, `latcheinit`, `addrreg0/1`

## 预取提示

- `CartBR` / `CartBROB`：在当前 2 KiB PRG 页面内预取下一 cache line（`&p[A + 64]`），带边界检查避免跨页。
- `FFCEUX_PPURead_Default`：在当前 1 KiB CHR 页面内预取下一 cache line（`&VPage[tmp >> 10][tmp + 64]`）。

## Savestate 兼容性

所有对齐只改变对象的对齐地址，**不改变类型大小**。`SFORMAT` 按字节大小序列化，因此：

- 已保存的 state chunk 大小不变。
- 720 帧 `rom_regression_test` CRC 与 `golden_hashes.json` 保持一致。
- 没有新增需要序列化的派生表，loadstate 后无需重建额外状态。
