### 2.1 vbl_05（决策 ROM，当前 PASS）E1B 序列节选（120 帧实测）

```
E1B VBL_SET  abs=59564  sl=0   cycle=0  count=-128 lastpc=E86B PPU_status_pre=0x00   ← 首帧（reset 短帧）
E1B VBL_CLR  abs=61836  sl=261 cycle=0  ...
E1B VBL_SET  abs=89343  sl=240 cycle=0  ...                                          ← 常规帧：VBL 于 sl240c0 块入口置位
E1B VBL_CLR  abs=91618  sl=261 cycle=0  ...                                          ← 20 扫描线后清除（6820 dots）
E1B VBL_CLR  abs=151180 sl=261 cycle=0  ...                                          ← 抑制帧（无 VBL_SET 行 = 被 $2002 读抑制）
...
E1B VBL_SET  abs=595615 sl=240 cycle=0  count=-80 ...
E1B NMI_LATCH abs=595617 sl=241 cycle=0 count=-48 PPU_status=0x80 VBlankON=1          ← NMI 于 VBL_SET 后 2 abs 派发（X6502_Run(8)）
E1B NMI_LATCH_CALLEE abs=595617 (path=VBL) count=-48 IRQlow_pre=0x200 lastpc=E352
```

要点：
- **VBL 置位点 = 块入口（sl240 c0 语义）**，清除在 20 扫描线后（sl261 c0），实测 Δ=2275 abs
  ≈ 6825 dots，与「6820-dot VBL」工作配置一致（±5 dots 为 abs 单位量化）。
- **NMI 派发 = VBL_SET + 2 abs**（X6502_Run(8) 预算后），与 v1.16 Step 1.3 的 nd=8 校准一致。
- 抑制帧存在（`VBL_CLR` 孤立行），证明 $2002 读抑制机制在置位层面生效。

### 2.2 vbl_06 / vbl_07 / vbl_08 的 NMI 行为差异（120 帧实测）

| ROM | NMI_LATCH 数 | 关键观察 |
|---|---|---|
| vbl_06_suppression | 14 | 多次 `PPU_status=0x00` 时仍 NMI_LATCH → **VBL 已被 $2002 读清除但 NMI 照发**（NMI 取消缺口，v1.16 已定位） |
| vbl_07_nmi_on_timing | 0 | NMI 全走 $2000 写边沿（`TriggerNMI2`），不经 VBL 路径 → 独立机制 |
| vbl_08_nmi_off_timing | 8 | 全 `PPU_status=0x80`，触发正常，错在转换行（早 2） |

vbl_07 的 `W2000 → NMI_SET2 → NMI_DISPATCH(+2)` 序列证实 $2000 边沿采样路径工作，
错位源于**写落点被指令边界量化**（与 vbl_02/06 同根因）。
