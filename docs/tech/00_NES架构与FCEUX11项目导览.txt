1. NES 是什么？一台 1983 年的游戏机怎么用 6502 + 卡带拼出超级玛丽？
================================================================================

  NES（Nintendo Entertainment System，俗称「红白机」「FC」）1983 年发售时，
  内部其实只集成了三块自研芯片 + 一颗 6502 衍生 CPU：

  ┌──────────────────────────────────────────────────────────────┐
  │                   NES 主机内部硬件概览                         │
  │                                                              │
  │   ┌─────────┐    ┌─────────┐    ┌─────────┐                 │
  │   │  CPU    │    │  PPU    │    │  APU    │                 │
  │   │ 2A03    │    │ 2C02    │    │ (在2A03 │                 │
  │   │ MOS 6502│    │ 图像    │    │  内)    │                 │
  │   │ 衍生    │    │ 处理器  │    │ 5通道   │                 │
  │   │ 1.79MHz │    │ 5.37MHz │    │ 声音    │                 │
  │   └────┬────┘    └────┬────┘    └────┬────┘                 │
  │        │ 地址总线     │              │                       │
  │        │ AD0–AD15     │              │                       │
  │        ▼              ▼              ▼                       │
  │   ┌──────────────────────────────────────────┐               │
  │   │          卡带插槽 (Cartridge Slot)        │               │
  │   │   - PRG-ROM (程序)                        │               │
  │   │   - CHR-ROM (图像)  或 CHR-RAM            │               │
  │   │   - Mapper 芯片  (可选)                   │               │
  │   │   - WRAM (可选，电池供电)                 │               │
  │   └──────────────────────────────────────────┘               │
  │                                                              │
  │   控制器端口 (D-pad + A/B/Start/Select / Zapper / Arkanoid)   │
  └──────────────────────────────────────────────────────────────┘

  你可以把这台机器理解为：
    - CPU 2A03：执行游戏逻辑（mov 字节、判断按钮、写 PPU 寄存器）
    - PPU 2C02：负责把 240×256 像素画到电视上，与 CPU 并行工作
    - APU：CPU 芯片内置，5 个声音通道（2 方波 + 三角波 + 噪声 + DMC）
    - 卡带插槽：把游戏 ROM 插进来；卡带上除了 ROM 还可以放 mapper 芯片

  这就是为什么 NES 模拟器的核心代码就是围绕这「三件套 + 卡带」展开。

2. 为什么 NES 需要 mapper？（最重要的入门概念）
================================================================================

  2.1 地址空间的硬约束

  6502 CPU 只有 16 位地址线，能访问 64 KiB 内存。但超级玛丽的卡带是
  320 KiB 的 PRG-ROM，塞尔达传说更大。怎么办？

  答案：CPU 不能直接寻址全部 ROM，必须通过「bank switching（分页切换）」
  让卡带上的不同 ROM 区域分时出现在 CPU 的 64 KiB 地址空间中。

  2.2 mapper 是什么？

  Mapper 是一片逻辑电路，藏在卡带里。它通过 CPU 写入「bank 寄存器」
  决定「CPU 这次访问 0x8000–0x9FFF 时，看到的是卡带 ROM 的哪一段」。
  不同游戏用不同 mapper 协议，于是 iNES 头里有个 mapper ID 字段。

  2.3 一个具体的例子（MMC3，最常见的 mapper）

  MMC3 把 PRG-ROM 切成 8 KiB 一页的窗口：

    CPU 地址                始终映射到的 PRG 块
    ─────────────────      ──────────────────────
    $6000–$7FFF            WRAM（如有）
    $8000–$9FFF            4 个可切换 bank 之一（由 $8000 写入选择）
    $A000–$BFFF            2 个可切换 bank 之一
    $C000–$DFFF            固定为倒数第二页
    $E000–$FFFF            固定为最后一页（reset/IRQ 向量在这里）

  最后两页固定，目的是让 NMI/IRQ/Reset 的中断向量（$FFFA-$FFFF）始终
  可见。MMC3 还支持通过 PPU 扫描线触发 IRQ，用来分屏。

  2.4 mapper 编号（iNES Mapper ID）

  FCEUX11 支持 200+ mapper，最常见的几个：
    - Mapper 0   : NROM（最简单，32 KiB 固定或镜像）
    - Mapper 1   : MMC1（塞尔达、银河战士、最终幻想）
    - Mapper 2   : UxROM（恶魔城、魂斗罗）
    - Mapper 3   : CNROM（俄罗斯方块、淘金者）
    - Mapper 4   : MMC3（超级玛丽 3、魂斗罗 6、口袋妖怪）
    - Mapper 7   : AOROM
    - Mapper 9   : MMC2
    - Mapper 10  : MMC4
    - Mapper 11  : Color Dreams
    - Mapper 66  : GxROM

  详见第 04 章「Mapper 与扩展芯片原理」。

3. FCEUX11 是什么？和 FCEUX 是什么关系？
================================================================================

  FCEUX 是最经典的 NES 模拟器（fork 自 FCE Ultra），已有 20+ 年历史。
  FCEUX11 是 2023 年开始的衍生项目，目标是：

    - 仅支持 Windows 11 + MSVC（去掉 Linux / macOS / MinGW 维护负担）
    - 引入 Qt 6 现代化 GUI
    - 把 C++ 模块逐步迁移到 Rust（v0.2.1 启动，v0.3.x 加速）
    - 保留原 FCEUX 的 99% 模拟精度（TAS 工具完整兼容）

  版本号含义（语义化版本）：
    0.3.x ：C-track（API 现代化、类型系统强化、性能工程）
    0.4.x ：B-track（开始动 emulator 核心 loop、APU 音质、OpenGL 重构）

  截至本文件，main 分支上已经完成 v0.3.10（API 收敛）和 v0.3.14
  （Qt/SDL 键盘双路径修复）。

7. 常见入门问题速答
================================================================================

  Q1: FCEUX11 是用 C++ 还是 Rust？
  A: 主体仍是 C++（继承自 FCEUX）。Rust 用于工具类、格式解析、媒体处理等
     「无状态」模块，从 v0.2.1 开始逐步替换。CPU/PPU/APU 核心仍是 C++，
     因为它们是 cycle-accurate 的状态机，重写风险极高（参见 09 §v0.3.x 计划）。

  Q2: 模拟器最难的部分是什么？
  A: mapper。FCEUX11 有 175+ mapper，每个都是「卡带厂商的私有协议」，
     而且其中很多是 1985–1995 年间用 TTL 芯片搭出来的非标电路，需要
     看实机示波器波形才能完全确认。详见 04。

  Q3: 跑通 FCEUX11 需要什么环境？
  A: Windows 11 + Visual Studio 2022 BuildTools (C++ workload) +
     CMake 4.0+ + Ninja + vcpkg + Rust（可选）。详见 13。

  Q4: TAS 录像兼容性如何？
  A: 完全兼容原 FCEUX 的 .fm2 / .fcm 格式。详见 05 与 14。

  Q5: 我是 6502 汇编新手，能从 FCEUX11 学到什么？
  A: 实际上 FCEUX11 的 6502 模拟器（x6502.cpp）是教学级的「6502 CPU
     模型」实现：56 个官方指令 + 不官方指令、13 种寻址方式、cycle
     accurate 调度。强烈建议读 src/ops_table.inc + 01 章。
