【写在前面 / Preface】
================================================================================

  NES 声音系统对入门者来说常常被忽略，但实际工程量不亚于 PPU。2A03
  内置 5 个声音通道、1 个帧计数器、1 个 DMC 单元，全部在 CPU 地址
  空间 $4000-$4017 内。FCEUX11 的 APU 模拟在 src/sound.cpp。

  本章目标：
    1. 解释 APU 5 个通道的整体架构
    2. 拆解方波（占空比 + 扫频 + 包络）的细节
    3. 拆解三角波（线性计数器 + 4-bit DAC）
    4. 拆解噪声（15-bit LFSR 伪随机）
    5. 拆解 DMC（Delta 调制 + DMA）
    6. 解释帧计数器 $4017 怎么分时驱动 5 通道
    7. 解释 FCEUX11 怎么从通道输出混成 1 路音频

  阅读时间：约 30 分钟。
  前置知识：懂基础信号处理（采样、量化、混音）即可。

================================================================================
1. 5 个通道总览
================================================================================

  ┌────┬───────────┬──────────────┬────────────────────────────────┐
  │ #  │ 通道       │ 频率范围     │ 主要用途                       │
  ├────┼───────────┼──────────────┼────────────────────────────────┤
  │ 1  │ 方波 1     │ 54.6 Hz-12.4kHz│ 主旋律、左声道                │
  │ 2  │ 方波 2     │ 同上          │ 副旋律、右声道                │
  │ 3  │ 三角波     │ 27.3 Hz-55.9kHz│ 低频贝斯、PWM 调制           │
  │ 4  │ 噪声       │ 29.3 Hz-447kHz│ 鼓声、风声、爆炸              │
  │ 5  │ DMC        │ 4.2kHz-33.1kHz│ 采样回放、1-bit ADC 风格鼓声  │
  └────┴───────────┴──────────────┴────────────────────────────────┘

  4 个主通道（方波 × 2、三角波、噪声）混合进一个 4-bit DAC。
  DMC 有自己的 7-bit DAC，与主 DAC 共享输出总线。

================================================================================
2. 寄存器映射：$4000-$4017
================================================================================

  每个通道占 4 个寄存器：

  ┌────────┬────────┬────────┬────────┬──────────────────────────────────┐
  │ 通道    │ 控制    │ 扫频    │ 频率低 │ 频率高 + 长度                     │
  ├────────┼────────┼────────┼────────┼──────────────────────────────────┤
  │ Square1│ $4000  │ $4001  │ $4002  │ $4003                            │
  │ Square2│ $4004  │ $4005  │ $4006  │ $4007                            │
  │ Triangle│$4008  │ (无)   │ $400A  │ $400B                            │
  │ Noise  │ $400C  │ (无)   │ $400E  │ $400F                            │
  │ DMC    │ $4010  │ (无)   │ $4012  │ $4013                            │
  └────────┴────────┴────────┴────────┴──────────────────────────────────┘

  特殊寄存器：
    $4015：状态 / 启用位（1 字节，写 = 启用通道；读 = 通道状态）
    $4017：帧计数器模式（4 步 / 5 步）

================================================================================
3. 方波通道：4 个组件的复合（最复杂的一个）
================================================================================

  方波通道由 4 个子模块级联：

  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌─────┐
  │ 12-bit   │ -> │ 扫频单元 │ -> │ 占空比   │ -> │ 包络/音量│ -> │ 4b  │
  │ 周期定时 │    │ 修正频率 │    │ 发生器   │    │ 调制     │    │ DAC │
  └──────────┘    └──────────┘    └──────────┘    └──────────┘    └─────┘

  3.1 占空比（$4000/$4004 高 2 位）

    4 种占空比：2/14, 4/12, 8/8, 12/4（高电平周期/整个周期）
    NES 真实硬件的占空比是「模拟波形」（不是数字方波），但模拟器
    通常按数字近似处理。FCEUX11 用 Brad Taylor nessound 文档的占空比表。

  3.2 长度计数器（length counter）

    7-bit 减计数器，60 Hz 步进。到 0 时通道静音。
    写入 $4003/$4007 的高 5 位会从内置查找表加载初值（详见 §10）。
    $4000.5=1 时长度计数器暂停（而不是到 0 自动静音）。

  3.3 包络（envelope）

    4-bit 减计数器，频率 = 240 Hz / (N+1)。到 0 后：
      $4000.5=0：保持 0（音量归 0）→ 通道静音
      $4000.5=1：环绕到 $F（继续发声）
    $4000.4=0 时用包络作为输出音量，$4000.4=1 时固定用 $4000 低 4 位。

  3.4 扫频（sweep unit）

    每次「4 步帧序列」的第 2/4 步触发：
      新波长 = 当前波长 ± (当前波长 >> 右移量)
      $4001.3=0 时加（频率升高），=1 时减（频率降低）
    加模式下若溢出或新波长 < $008 → 通道静音。
    Square 1 向下扫频用 1's complement，Square 2 用 2's complement（细节差异）。

================================================================================
4. 三角波通道：简单、干净、专做低频
================================================================================

  三角波只有 3 个子模块：
    - 12-bit 周期定时器（不可扫频）
    - 32 步三角阶梯（4-bit DAC 输出）
    - 7-bit 线性计数器（240 Hz，可装载、可暂停）

  $4008.7 = 0 时使用线性计数器（控制通道使能）。
  $4008.6-0 = 线性计数器的装载值。

  三角波因为是 4-bit DAC，所以实际听感「柔」一些，常用于：
    - 贝斯线（频率低、波形柔）
    - 主旋律
    - PWM 调制（许多游戏在 APU 三角上做 PWM 模拟乐器音色）

================================================================================
5. 噪声通道：15-bit LFSR
================================================================================

  噪声通道用一个 15-bit 线性反馈移位寄存器（LFSR）产生伪随机序列：
    32K 模式：tap = bit 0, 1（短周期，听感更"白"）
    93-bit 模式：tap = bit 0, 6（长周期，听感更"金属"）

  频率由 $400E 的低 4 位查表得到（16 档预置频率，从 29.3 Hz 到 447 kHz）。
  噪声主要用途：鼓、爆炸、风、雨、激光。

  噪声通道也有包络和长度计数器（与方波共用机制），但无扫频。

================================================================================
6. DMC：Delta 调制 + DMA
================================================================================

  DMC（Delta Modulation Channel）是 APU 里最"奇怪"的一个。它本质
  是 1-bit DAC 风格 的"采样回放"通道：

  6.1 工作流程

    1. 游戏写 $4012/$4013：起始地址 = $4012 << 6 | $C000，长度 = ($4013 << 4) + 1
    2. APU 启动 DMA 周期：从 $C000 + offset 取 1 字节
       （每次取 1 字节会让 CPU 暂停 1 周期）
    3. 字节载入 8-bit 移位寄存器
    4. 移位寄存器以 8× DMA 频率逐位输出
    5. 每位：
         1 → 6-bit delta 计数器 +1
         0 → delta 计数器 -1
    6. delta 计数器高 6 位连到 7-bit DAC 的高 6 位，最低位（counter bit 0）
       直接连 DAC bit 0。
    7. delta 计数器到 0 再减 / $3F 再加时"截断"（不环绕）。

  6.2 寄存器 $4010

    bit 7   : IRQ enable (1 = 播放结束产生 IRQ)
    bit 6   : Loop (1 = 播放结束自动回到起点)
    bit 3-0 : 频率索引 (16 档 DMA 频率)

  6.3 直接写 $4011 的妙用

    $4011 是 7-bit delta 计数器初值。游戏有时直接写 $4011 来生成
    "伪 PCM" 效果（例如 Mega Man 2 的部分音效）。FCEUX11 正确模拟。

================================================================================
7. 帧计数器 $4017：APU 的"心跳"
================================================================================

  $4017.7 = 0：4 步序列（60Hz 帧 IRQ）
    1st → 2nd → 3rd → 4th(IRQ) → 5th(1st) → ...
    每步 7457 CPU 周期，共 29829.6 周期/帧
    - 1st/3rd/5th（奇数）：包络衰减、线性计数器更新
    - 2nd/4th/6th（偶数）：包络衰减、线性计数器、长度计数器、扫频更新

  $4017.7 = 1：5 步序列（48Hz，无帧 IRQ）
    1st(立即) → 2nd → 3rd → 4th → 5th(14914 周期) → 6th(1st) → ...
    - 1st 立即执行（不是 7457 周期后）
    - 5th 后下一帧从 1st 开始

  复位 $4011 的 7 个有效位，IRQ 标志清除，通道禁用。

  上电时 $4017.7 默认 0（4 步、60Hz、有 IRQ）。系统复位（vs 软复位）
  不重置 $4017 内容。

================================================================================
8. $4015 状态 / 启用寄存器
================================================================================

  读 $4015：
    bit 0-3 : 4 个通道的"长度计数器 != 0" 状态
    bit 4   : DMC 通道是否在播放
    bit 6   : 帧 IRQ 标志
    bit 7   : DMC IRQ 标志
    读 $4015 会清除 IRQ 标志吗？答案：不！只有写 $4015 才清除。

  写 $4015：
    bit 0-3 = 1：启用对应通道；= 0：禁用（清空长度计数器）
    bit 4   = 1：启用 DMC；= 0：禁用
    写入会清除帧 IRQ 与 DMC IRQ 标志。

  首次启用一个通道后，有 2048 CPU 周期延迟才开始正常时钟（防止
  突然启用产生的"啪"声）。

9. 输出：4 通道 + DMC 怎么混成 1 路音频？
================================================================================

  NES 真实硬件有 4-bit 主 DAC 和 7-bit DMC DAC。
  FCEUX11 的模拟：

    for each output_sample (e.g. 44100 Hz, 1.79 MHz CPU):
        s1 = square1.output();   // 0..15
        s2 = square2.output();   // 0..15
        t  = triangle.output();  // 0..15
        n  = noise.output();     // 0..15
        dmc = dmc.output();      // 0..127

        // 查找表 / 公式混合（Brad Taylor 给出经验值）
        out = lookup_table[s1 + s2 + t + n] + dmc_lookup[dmc];

        // 写进 host audio buffer

  FCEUX11 的 host 输出：
    - 默认 44100 Hz，16-bit 立体声
    - 缓冲区经 c44100ntsc.c 提供的 FIR 滤波器平滑（src/fir/c44100ntsc.coef）
    - 通过 SDL_QueueAudio 或 Qt QAudioSink 推给操作系统

10. 长度计数器查找表
================================================================================

  写入 $4003/$4007 高 5 位 = 长度查找表索引：

  ┌──────────┬────────────┬────────────┐
  │ index    │ $4000.5=0  │ $4000.5=1  │
  ├──────────┼────────────┼────────────┤
  │ 0        │ 5          │ 6          │
  │ 1        │ 0A         │ 0C         │
  │ 2        │ 14         │ 18         │
  │ 3        │ 28         │ 30         │
  │ 4        │ 50         │ 60         │
  │ 5        │ 1E         │ 24         │
  │ 6        │ 07         │ 08         │
  │ 7        │ 0D         │ 10         │
  └──────────┴────────────┴────────────┘

  如果 bit 3=1，则直接映射 0-15 → 7F, 01, 02, ..., 0F 帧。
  （即"长度最长可达 127 帧"）
