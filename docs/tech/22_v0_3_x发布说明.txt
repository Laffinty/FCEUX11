2. 子版本亮点（17 + 2 检查点）
================================================================================

  2.1 前置（v0.3.0）

    - 测试基建：引入 nestest.nes + 15 ROM fixture
    - 性能基线：3 个 Google Benchmark 风格 binary
    - 字节级 savestate 框架：tests/fixtures/golden_hashes.json
    - CI workflow：4 阶段（build → ctest → rom_regression → benchmark）

  2.2 A 轨道：工具链（v0.3.1, v0.3.2）

    - v0.3.1：MSVC 19.36+ 锁定 + Qt 6.8 LTS + /W4 软启动
    - v0.3.2：CMake 4.0 + git-cliff + cppcheck（v0.3.6.6 移除 clang-tidy）

  2.3 B 轨道：安全（v0.3.3 ~ v0.3.6, v0.3.6.5, v0.3.6.6）

    - v0.3.3：C++20 完备化（std::span + tl::expected + <format>）
    - v0.3.4：死代码清理（types-des.h、MACRODO/ARM9 残留）
    - v0.3.5：缓冲区安全（sprintf/strcpy 全量替换，safe_string.h）
    - v0.3.6：RAII 化（unique_ptr 替代 FCEU_malloc，4 套分配器合并）
    - v0.3.6.5：整合检查点 1 — ASan/UBSan 跑通 + 12 项 CodeReview 收尾
    - v0.3.6.6：errata 收尾（clang 工具链清理 + 工具链政策强化）

  2.4 C 轨道：API 现代化（v0.3.7 ~ v0.3.10）

    - v0.3.7：types.h 职责拆分 + 新符号入 fceu11:: 命名空间
    - v0.3.8：enum class 化（ESI / ESIFC / AllocKind / IoDir）
    - v0.3.9：driver.h 物理拆分（core_api.h / io_api.h / net_api.h /
              diag_api.h）— FCEUI_* 250+ 符号收敛起点
    - v0.3.10：FCEUI_* 收敛 1118 → 594 + EMUFILE std::span 化
              （30+ call sites 经 P3.1-P3.6 6 个 batch 迁移）

  2.5 D 轨道：性能（v0.3.11, v0.3.12, v0.3.12.5）

    - v0.3.11：PPU 缓存优化（alignas(64) ppulut1/2/3）+ x6502
              std::array 跳转表 + SIMD probe 报告
    - v0.3.12：mapper 寄存器组 64-byte 对齐 + PRG/CHR 切换表预取
    - v0.3.12.5：整合检查点 2 — 性能回归 vs v0.3.0 baseline 通过

  2.6 E 轨道：Win11 平台特性（v0.3.13, v0.3.14, v0.3.15）

    - v0.3.13：输入系统重构（XInput/SDL/WGI 插件化，WGI opt-in）
    - v0.3.14：视频后端 OpenGL Core Profile 3.3 + QOpenGLWindow
              + 3 项 BUG 修复（启动崩溃/键盘失效/伪终端）
    - v0.3.15：PerMonitorV2 + 暗色模式 + Snap Layouts + Qt6 现代化
              + 主菜单 5+1 受众分层重构 + i18n 基础设施

  2.7 F 轨道：i18n（v0.3.15 PR-B/PR-C）

    - PR-B：lupdate/lrelease pipeline + 字体 fallback 链
    - PR-C：zh_CN/zh_TW 翻译填充（99.74% 覆盖，2026-06-17 母语
            审校 waive）

  2.8 G 轨道：收官 LTS（v0.3.16）

    - /WX 激活（铁律 11）+ 已知 /wd 抑制（带文档化理由）
    - FCEUX11_NO_DEPRECATION_WARNINGS 项目级默认 ON（CMake）
    - 5 个 Win11 平台特性集（详见 19 章）
    - 4 篇新沉淀文档（19/20/21/22 章）+ 3 篇 16/17/18 章节
    - CHANGELOG.md 整合 v0.3.0 ~ v0.3.16 全部 17+2 检查点
    - readme.md 同步 Win11 LTS 状态

3. 兼容性策略（v0.2.x → v0.3.x）
================================================================================

  3.1 字节级 savestate 兼容

    v0.3.0 ~ v0.3.16 期间，savestate 字节布局保持稳定（铁律 1）。
    v0.2.x 写入的 .fc0 / .fcs 文件可在 v0.3.16 直接加载。
    v0.3.0 起的 golden_hashes.json 与 v0.2.30 baseline 字节一致。

  3.2 INI 配置兼容

    QSettings keys 全部保留（PHASE-4 TypedConfig<T> 是 additive）。
    新 key（SDL.HideAdvancedMenu / General/Language 等）首次启动
    以默认值初始化。
    现有用户 INI 文件不需手动迁移。

  3.3 公共 API 兼容

    - 250+ FCEUI_* 符号保留为 inline shim（v0.4.0 才删）
    - fceuScopedPtr<T> 保留为 [[deprecated]] alias
    - FCEU_malloc/free/dmalloc/dfree 保留为 [[deprecated]]
    - EMUFILE (void*, size_t) 保留为 [[deprecated]] shim
    - driver.h 是 20 行 shim，重新 include 4 个新头

  3.4 工具链不兼容

    - **仅支持 MSVC 14.51+**（v0.3.6.5 起锁定；plan §3.1 铁律 9）
    - **拒绝** clang-cl / gcc / MinGW / MSYS2
    - **拒绝** Qt < 6.8 LTS
    - v0.2.x 时代 MinGW-w64 用户：必须迁移到 MSVC（文档见
      [docs/tech/13_构建系统与CI矩阵.txt](13_构建系统与CI矩阵.txt)）

  3.5 性能特性

    - PPU 渲染 < 1.1× v0.3.0 baseline（实测 0.975×）
    - CPU 执行 < 0.95× v0.3.0 baseline（实测 0.90×）
    - APU mix informational（实测 1.02×，变化在抖动范围内）

8. 升级路径
================================================================================

  8.1 从 v0.3.15 升级

    1. 备份 %APPDATA%\FCEUX11\fceux11.ini
    2. 解压 fceux11-v0.3.16-win64.zip 到新目录
    3. 启动新二进制，旧 INI 自动加载
    4. 验证：F5/F7/F2/Esc 快捷键 + 5+1 菜单结构 + 三语切换
    5. 删除旧目录（保留备份 1 周）

  8.2 从 v0.3.14 升级

    同上。主菜单布局变化（7 菜单 → 5+1 收纳），参考迁移表：
    [docs/tech/Menu_Migration_v0.3.15.md](Menu_Migration_v0.3.15.md)

  8.3 从 v0.2.x 升级（破坏性）

    v0.2.x 时代 MinGW-w64 用户：
    1. 卸载 v0.2.x
    2. 安装 MSVC 14.51+（VS 18 BuildTools）
    3. 安装 vcpkg + Qt 6.8 LTS + SDL2 2.30.5
    4. 编译 fceux11 v0.3.16（CMake 4.0）
    5. 迁移 INI：%APPDATA%\.fceux11\  → %APPDATA%\FCEUX11\
    6. savestate 文件格式不变（.fc0 / .fcs 兼容）
    详细步骤：docs/tech/13_构建系统与CI矩阵.txt
