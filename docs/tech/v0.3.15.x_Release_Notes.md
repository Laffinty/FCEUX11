## 1. Headline

This release closes the v0.3.15 plan by shipping the four follow-on PHASEs that were scaffolded but not yet merged at v0.3.15 main: full i18n coverage, 30+ sub-dialog runtime language switching, Win11 platform-feature completion, and QSettings / high-DPI refactors. The release preserves every v0.3.14 emulation-correctness guarantee (savestate byte layout, hotkey bindings, ROM hashes).

---

## 2. Highlights

### 2.1 Main menu: 5+1 audience-tiered model (BREAKING-LAYOUT)

The Tools / Debug / Movie top-level menus are now collected under a new **Advanced** menu as five sub-menus (Emulation / Movie / Debug / Memory Tools / Misc Tools / Advanced Settings). The top-level menu bar is:

```
File  Emulation  Options  Advanced  Help
```

For minimal-noise workflows, **Options → GUI Config → Hide Advanced Menu** collapses the bar to four entries. Existing hotkeys (F5 reset, F7 load state, F2 pause, Esc close, etc.) are unchanged — only the menu tree was restructured.

Migration table: [`docs/tech/Menu_Migration_v0.3.15.md`](Menu_Migration_v0.3.15.md).

### 2.2 Full zh_CN / zh_TW translation (99.74% coverage)

```
$ powershell scripts/i18n_coverage.ps1
[PASS] zh_CN: 1906/1911 translated (99.74%) -- gate 90%
[PASS] zh_TW: 1906/1911 translated (99.74%) -- gate 90%

$ powershell scripts/check_simp_trad.ps1
[PASS] fceux11_zh_CN.ts (no traditional): no forbidden glyphs found.
[PASS] fceux11_zh_TW.ts (no simplified): no forbidden glyphs found.
```

The 0.26% gap (5 strings per language) is reserved for technical proper-nouns that have no idiomatic translation (e.g. mapper numbers, CPU register mnemonics). See glossary.txt for the 80-entry term table that governs machine-translation consistency. **Per the 2026-06-17 user decision, native-speaker review was waived for this release** — the LLM-only translation is shipped at 99.74% to unblock the LTS release; a community PR for native review can land in v0.3.15.x+1 without re-doing the LLM pass.

### 2.3 34 sub-dialogs respond to runtime language switch

The Qt widget tree below the main menu now responds to `QEvent::LanguageChange`. Switch language at runtime and the active window — ConsoleDebugger, TasEditor, PPU Viewer, HexEditor, AVI Record, GamePad Config, GUI Config, RAM Watch, Trace Logger, Console Video Config, Code/Data Logger, iNES Header Editor, Cheats Config, Name Table Viewer, Movie Play, Palette Editor, State Recorder Config, Family Keyboard, Frame Timing Stats, RAM Search, Input Config, Movie Record, Palette Config, Symbolic Debug, Game Genie, Console Sound Config, Timing Config, Help Pages, Lua Control, Movie Options, HotKey Config, plus the 4 TasEditor sub-files (branches / splicer / project / bookmarks) — all refresh within one frame of the language switch.

The change is structurally minimal: every sub-dialog declares a `retranslateUi()` private slot; `changeEvent(QEvent*)` overrides call it on `QEvent::LanguageChange`. The 6 `keyPress override` files (HexEditor / HotKeyConf / FamilyKeyboard — the original 3 from v0.3.15 main, plus the 3 added in PHASE-2) all forward to `QWidget::keyPressEvent(event)` first so Chinese IME composition reaches focused `QLineEdit` widgets.

## 3. What This Release Does NOT Change

- **Emulation correctness** — `rom_regression_test` (Gate 3) confirms 5 ROMs × 60 frames produce byte-identical hashes to v0.3.14.
- **Savestate byte layout** — `savestate_regression_test` (Gate 2) confirms `.fc0` / `.fcs` files are bit-exact.
- **Hotkey bindings** — `initHotKeys()` was not touched in any PHASE-1~5 commit; F5 / F7 / F2 / Esc still work as in v0.3.14.
- **External API surface** — `QSettings` keys, default values, and on-disk INI format are preserved. Existing user configurations migrate without intervention.
- **Toolchain** — VS 18 BuildTools MSVC 14.51.36231 + vcpkg (Qt 6.8.0 LTS, SDL2 2.30.5, fmt 10.x). No new compiler dependencies.

## 4. Upgrade Notes

### 4.1 From v0.3.14

Drop-in replacement. Run `fceux11-v0.3.15.x-win64.zip` and the existing `fceux11.ini` is honored. The main menu layout changes — see the migration table in [`docs/tech/Menu_Migration_v0.3.15.md`](Menu_Migration_v0.3.15.md) for where each v0.3.14 menu item lives now.

### 4.2 From v0.3.15 main

This is a continuation release. If you installed the v0.3.15 main pre-release and noticed the "Hide Advanced Menu" toggle and the 20-seed translation only, those features are now fully wired in v0.3.15.x:
- All 34 sub-dialogs respond to runtime language switch (not just the main menu).
- 1,906 / 1,911 tr() strings are translated in zh_CN / zh_TW (was 20 / 1,911 in v0.3.15 main).
- Win11 dark-mode detection no longer relies on registry polling.
- DirectStorage probe is integrated (was a stub in v0.3.15 main).
- Taskbar progress + overlay icon for TAS recording.

### 4.3 Configuration migration

`TypedConfig<T>` wraps QSettings transparently. Existing user INI files are read identically and the keys/values they contain are unchanged. New keys (`SDL.HideAdvancedMenu`) appear on first run with their default value (`false`).
