================================================================================
std::byte 转换规则（FCEUX11 跨边界类型安全）
================================================================================

适用：FCEUX11 项目所有 C++20 代码，特别是 EMUFILE、ROM 加载器、savestate
序列化、mapper 寄存器访问等"字节"密集型路径。

本文档抽取自 v0.3.10 落地参考的 §9–10（`06_v0.3.10_API_Convergence_Reference.txt`），
合并 EMUFILE std::span 化时的所有迁移模板与反模式。任何后续修改类型边界
（std::span / std::byte / std::vector<std::byte>）前，先读本文档确认是否踩
到 §4 的禁止模式。

================================================================================
1. 设计原则
================================================================================

1.1 std::byte 只表示"原始字节"，**不**参与算术运算。
    • 含义：内存中的 8 位数据，零和一的集合。
    • 不能：`b + 1`, `b * 2`, `b > 0`, `b & 0xFF`。
    • 只能：`std::to_integer<T>(b)` 转回整数后做算术。

1.2 uint8_t / u8 仍表示"无符号 8 位整数"，可用于索引、计数、位运算。
    • 用在：循环索引、位标志、掩码运算、C 风格内存拷贝。
    • 不用于：跨越类型边界的"字节载荷"。

1.3 跨边界转换必须显式。
    数值 → 字节：`std::byte{val}`
    字节 → 数值：`std::to_integer<T>(b)`
    不允许 implicit conversion（编译器应拒绝，但显式更清晰）。

1.4 兼容 shim 保留到 v0.4.0。
    EMUFILE 旧的 fread(void*, size_t) / fwrite(const void*, size_t) 接口
    用 `[[deprecated]]` 标记，但二进制兼容。

================================================================================
2. EMUFILE 调用方迁移模板
================================================================================

2.1 固定缓冲区读取

    // 旧
    uint8_t buf[16];
    size_t n = emuf->fread(buf, 16);

    // 新
    std::array<std::byte, 16> buf{};
    size_t n = emuf->fread(buf);

2.2 动态缓冲区读取

    // 旧
    std::vector<u8> data;
    data.resize(len);
    emuf->fread(data.data(), data.size());

    // 新
    std::vector<std::byte> data;
    data.resize(len);
    emuf->fread(data);

2.3 写入外部数据

    // 旧
    emuf->fwrite(ptr, size);

    // 新（临时桥接，ptr 是 const void*）
    emuf->fwrite(std::span<const std::byte>(
        reinterpret_cast<const std::byte*>(ptr), size));

2.4 写入单字节

    // 旧
    u8 val = 0x42;
    emuf->fwrite(&val, 1);

    // 新
    emuf->fwrite(std::span<const std::byte>(
        reinterpret_cast<const std::byte*>(&val), 1));

================================================================================
3. std::byte ↔ uint8_t / u8 边界
================================================================================

    // uint8_t → std::byte
    auto b = std::byte{val};

    // std::byte → uint8_t
    auto u = std::to_integer<uint8_t>(b);

    // 与 C API 交互（span 视图不拥有数据）
    some_c_api(reinterpret_cast<const uint8_t*>(span.data()), span.size());

    // 需要所有权时复制
    std::vector<u8> owned(u8_span.begin(), u8_span.end());

通用模式：内部 std::span<std::byte> 走类型安全路径，边界（C 库 / 第三方
SDK）用 reinterpret_cast 桥接。

================================================================================
4. 禁止与高风险模式
================================================================================

| 风险 | 禁止写法 | 推荐写法 |
|------|----------|----------|
| std::byte 算术 | `b = b + std::byte{1}` | `b = std::byte{std::to_integer<int>(b) + 1}` |
| 隐式整数提升 | `if (b > 0)` | `if (std::to_integer<int>(b) > 0)` |
| reinterpret_cast 混用 | `reinterpret_cast<u8*>(byte_ptr)` | std::span<const std::byte> 桥接，或在边界显式复制 |
| 直接对 std::byte* 做 memcpy | `memcpy(dst_byte_ptr, src_u8_ptr, n)` | 先 reinterpret_cast 到 std::byte*（同一对象 lifetype 不变），或复制到 std::vector<std::byte> |

================================================================================
5. 兼容 shim（保留到 v0.4.0）
================================================================================

    class EMUFILE {
    public:
        virtual size_t fread(std::span<std::byte> dst) = 0;
        virtual size_t fwrite(std::span<const std::byte> src) = 0;

        [[deprecated("use std::span overload")]]
        size_t fread(void* ptr, size_t size) {
            return fread(std::span<std::byte>(static_cast<std::byte*>(ptr), size));
        }
        [[deprecated("use std::span overload")]]
        size_t fwrite(const void* ptr, size_t size) {
            return fwrite(std::span<const std::byte>(static_cast<const std::byte*>(ptr), size));
        }
    };

shim 的关键点：
  - 虚函数接口必须用 std::span 重载，旧接口走 deprecated 桥接
  - 桥接里 static_cast<std::byte*>(void*) 安全，因为 std::byte 和 void*
    在底层表示相同（都是 raw byte），只是类型不同
  - 桥接里不能 reinterpret_cast（虽然结果一样），因为 reinterpret_cast
    暗示"重新解释类型"，与此处 "void* 本来就是字节指针" 的语义不符

================================================================================
6. 自动化检查
================================================================================

  - `scripts/_check_byte_usage.py` 扫描 HIGH / MED / LOW 风险
  - 迁移后应保证 `scripts/_check_byte_usage.py --fail-high 0` 通过
  - HIGH = 上述禁止写法第 1、3 行（算术 / reinterpret_cast 混用）
  - MED  = 隐式整数提升
  - LOW  = memcpy 字节指针（需要在 PR 中说明为什么不能改）
