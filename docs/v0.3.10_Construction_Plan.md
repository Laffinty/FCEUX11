# FCEUX11 v0.3.10 构建规划 — `FCEUI_*` 收敛 + `EMUFILE` `std::span` 化

> **Sub-version**: v0.3.10  
> **Track**: C（API 现代化）  
> **定位**: C 轨道收官子版本，承上启下：前接 v0.3.7/8/9 的类型系统重构，后启 v0.3.11 起的性能优化。  
> **状态**: P1 已完成（度量与脚本基建落地）  
> **Plan reference**: `docs/v0.3.x_Construction_Plan_v3.md` §5 v0.3.10

---

## 0. 文档导读

### 0.1 目标

1. 将源码树中 `FCEUI_*` 公共 API 符号从当前约 **1,118 处（文本 993 处）** 收敛到 **< 600 处**。
2. 将 `EMUFILE::fread` / `EMUFILE::fwrite` 的裸指针接口升级为 `std::span<std::byte>` / `std::span<const std::byte>`。
3. `EMUFILE_MEMORY` 内部存储从 `std::vector<u8>` 迁移到 `std::vector<std::byte>`。
4. 同步 `fceux11-formats::EmuFile` Rust 侧的调用边界（**仅改 C++ 包装层，不动 Rust crate**）。
5. 保证 **100% 字节级 savestate 一致性**：5 ROM savestate SHA-256 哈希与 v0.3.0 基线完全一致。

### 0.2 非目标

- 不删除任何兼容 shim；旧符号保留全局 `using` 别名，v0.4.0 才删除。
- 不新增 FFI 函数；v0.3.x 阶段 Rust crate 版本保持 0.2.x。
- 不改模拟器热路径算法；v0.3.10 是 API 形状现代化，不是性能优化。
- 不改动 mapper 行为、PPU/CPU/APU 时序、savestate 文件格式。

### 0.3 关键约束（不可违反）

| # | 约束 | 验证方式 |
|---|------|----------|
| 1 | 字节级 savestate 一致 | 5 ROM 60 帧 savestate SHA-256 与 `tests/fixtures/golden_hashes.json` 一致 |
| 2 | MSVC-only 工具链 | `CMakeLists.txt` 非 MSVC 直接 `FATAL_ERROR` |
| 3 | C++20 不升 23 | `CMAKE_CXX_STANDARD 20` |
| 4 | 兼容 shim 不删除 | 全局 `using` / `inline constexpr` 别名保留 |
| 5 | Rust crate 不动 | `cargo test --workspace` 全过；`fceux11_rust.h` 签名不增 |

## 1. 现状与基线

### 1.1 当前符号计数（实测）

```bash
# 2026-06-13 实测
grep -rn "FCEUI_" src/ | wc -l      # 1118
grep -rn "EMUFILE" src/ | wc -l     # 291
grep -rn "EMUFILE_MEMORY" src/ | wc -l   # 97
```

> 注：原 plan v3 写 1,167 处，该数字随 v0.3.7/8/9 的 `driver.h` 拆分等工作已自然下降。

### 1.2 `EMUFILE` 当前接口

`src/emufile.h` 中核心虚函数（v0.3.9 基线）：

```cpp
virtual size_t fread(void* ptr, size_t size) = 0;
virtual size_t fwrite(const void* ptr, size_t size) = 0;
```

`EMUFILE_MEMORY` 内部使用 `std::vector<u8>`（`uint8_t` 别名），调用方在 10+ 处直接访问 `buf()` / `get_vec()` 裸指针，是 v0.2.16 就判定为“暂缓”的高风险迁移点。

### 1.3 前置依赖（必须全部满足）

| 前置版本 | 状态 | 不启动 v0.3.10 的原因 |
|----------|------|------------------------|
| v0.3.7 `types.h` 拆分 | ✅ 已发布 | namespace 与平台兼容层未稳定 |
| v0.3.8 `enum class` 化 | ✅ 已发布 | 类型系统未稳定，无法安全 mass-rename |
| v0.3.9 `driver.h` 拆分 | ✅ 已发布 | API 头物理结构未清晰，收敛无从下手 |
| 5 ROM savestate 基线 | ✅ 已建立 | 无基线则无法验证字节级一致性 |

### 1.4 强后续依赖

- **v0.3.11** 强依赖 v0.3.10：PPU/CPU 缓存优化需要 `EmuFile::std::span` 化后稳定的 savestate 布局。

## 2. 风险登记与缓解

| 项 | 风险 | 等级 | 缓解 |
|----|------|------|------|
| R1 | `FCEUI_*` 1,118 处收敛遗漏外部调用方 / Lua / 插件 | ★★★★ | 保留全局 `using` 别名至 v0.4.0；`expected_api_test` 扩展覆盖 |
| R2 | `std::span` 改变 `EMUFILE` 调用约定或边界语义 | ★★★ | 保留旧签名 `[[deprecated]]` shim；每改一个调用方即编译验证 |
| R3 | `std::byte` 与 `uint8_t` 混用导致编译失败 | ★★★ | 统一转换规则：`std::to_integer<uint8_t>(b)` / `std::byte{val}`；静态扫描脚本 |
| R4 | savestate 字节级一致性破坏 | ★★★★★ | 每 Phase 后跑 5 ROM 哈希；不一致立即回滚 |
| R5 | Rust FFI 边界漂移 | ★★ | 仅改 C++ 包装层；变更需 RFC；`cargo test --workspace` 全过 |
| R6 | 调用方迁移顺序错误导致长时间无法编译 | ★★★ | 按依赖拓扑分批；每批独立 commit；优先迁移叶子调用方 |

## 3. 工具链与外部依据（已联网求证）

| 决策 | 依据 | 来源 |
|------|------|------|
| C++20 `std::span` 可用 | `<span>` 在 MSVC 2022 C++20 模式下完整实现 | Microsoft STL Wiki、MSVC C++20 博客 |
| `std::byte` 语义 | `std::byte` 不定义算术运算，需显式 `std::to_integer` / `std::byte{}` 转换 | C++ reference / Microsoft Learn |
| `std::span` 为 non-owning view | 不会复制底层数据，适合替换 `(ptr, size)` 参数对 | cppstories.com / C++ Core Guidelines |
| MSVC ASan flag 语法 | 必须 `/fsanitize=address`（等号），`/fsanitize:address` 会被 D9002 静默丢弃 | Microsoft Learn `/cpp/build/reference/fsanitize` |
| savestate 字节级一致性 | FCEUX 社区将 savestate 兼容性视为核心契约；任何序列化格式变动都会破坏 TAS / 录像回放 | FCEUX 官方站点与社区实践 |

## 7. 关键代码转换规则

### 7.1 `EMUFILE` 调用方适配模板

```cpp
// Before
uint8_t buf[16];
size_t n = emuf->fread(buf, 16);

// After
std::array<std::byte, 16> buf{};
size_t n = emuf->fread(buf);
```

```cpp
// Before
std::vector<u8> data;
data.resize(len);
emuf->fread(data.data(), data.size());

// After
std::vector<std::byte> data;
data.resize(len);
emuf->fread(data);
```

```cpp
// Before
emuf->fwrite(ptr, size);

// After
emuf->fwrite(std::span<const std::byte>(
    reinterpret_cast<const std::byte*>(ptr), size));
```

### 7.2 `std::byte` ↔ `uint8_t` 边界

```cpp
// uint8_t -> std::byte
auto b = std::byte{val};

// std::byte -> uint8_t
auto u = std::to_integer<uint8_t>(b);

// 与 C API 交互
some_c_api(reinterpret_cast<const uint8_t*>(span.data()), span.size());
```

### 7.3 兼容 shim（不删除）

```cpp
// emufile.h
class EMUFILE {
public:
    virtual size_t fread(std::span<std::byte> dst) = 0;
    virtual size_t fwrite(std::span<const std::byte> src) = 0;

    [[deprecated("use std::span overload")]]
    size_t fread(void* ptr, size_t size) {
        return fread(std::span<std::byte>(static_cast<std::byte*>(ptr), size));
    }
    [[deprecated("use std::span overload")]]
    size_t fwrite(const void* ptr, size_t size) {
        return fwrite(std::span<const std::byte>(static_cast<const std::byte*>(ptr), size));
    }
};
```
