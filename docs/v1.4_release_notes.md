# FCEUX11 v1.4 (Gateway) — Release Notes

> 发布日期：2026-06-23
> 上一个发布版本：v1.2
> 内部代号：**Gateway** —— 为后续 v1.5 / v1.6 / v1.7 子版本打开的统一内存分发通道。

---

## 用户可见的主要改进

### 兼容性更稳，多数 mapper 跑起来更可靠

**Compatibility improvements — most mappers run more reliably.**

将 175 个 mapper board 文件原本零散在各处的内存分发路径统一收口到一个统一的内部总线上，消除了 v1.2 / v1.3 期间累积的若干次不一致。对早期 / 多 mapper 混用的游戏卡带更宽容，启动崩溃、mapper 识别错误等问题减少。

> 内部行为对绝大多数用户不可见，**没有 API 变化**；少量罕见的 mapper 极端组合行为可能与 v1.2 略有差异，但均在设计目标范围内。

---

### 长时间运行更稳，CPU 调度与内存通路重写

**Stability overhaul: CPU dispatch and memory paths rewritten for longer crash-free sessions.**

CPU 每帧 ~10⁶ 次的取指 / 读写分发路径，以及 PPU 每帧 ~10⁵ 次的命名表 / 图形读取路径，在 v1.4 中改走统一的直接寻址，不再有 v1.4 早期候选版本上出现的引用别名间接寻址层。长时间挂机、Speedrun、连续录像回放等场景的卡顿与偶发崩溃显著减少。

> 帧率表现与 v1.2 持平或在多数场景略有提升；不允许退步的指标在性能门禁内。

---

### 旧 savestate 仍可加载，向前兼容路径已建立

**Backward-compatible savestate loading — v1.2 / v1.3 .fc0 files still load.**

v1.4 的存档格式版本号已更新到 `1.4`，但保留了与 v1.2 / v1.3 的字节级兼容。已有的 `.fc0` 存档、`.fm2` 录像均可继续加载、运行并以 v1.4 格式保存。

> 如果你正使用 v1.2 录像 + savestate 的连续回放，无需任何手动迁移。

---

### 全中文界面（简繁英三语）继续保留

**Full Chinese interface (Simplified + Traditional + English) preserved.**

与 v1.2 相同，菜单、对话框、提示信息均提供简体中文、繁体中文、英文三种语言切换，中文输入法与 CJK 字体正确显示。**v1.4 没有改动 i18n 文件**，翻译保持 v1.2 的 100% 覆盖。

---

### 已知问题与延迟项

**Known issues deferred to a future release.**

极少数特殊 mapper（目前已知：**Konami VRC7**，mapper 编号 85）涉及音频合成的 OPLL 内部状态在跨版本存档中存在非确定性指针差异。由于目前 VRC7 没有任何官方 golden 存档，**v1.4 暂未修复此问题**，将在后续 v1.7 重新统一处理。如果你不在使用 VRC7 mapper 的游戏（如 幻想空间 / Lagrange Point），**不会受到任何影响**。

---
