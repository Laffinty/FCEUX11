About

Introduction

FCEUX11 is a derivative of the FCEUX NES/Famicom emulator, actively maintained and optimized for Windows.

It preserves the core emulation accuracy of FCEUX while providing a modern, native Windows experience, including a Qt6-based user interface, multi-language support, and comprehensive debugging and TAS tooling.

What's new

v1.13 · Purify

Released 2026-07-10 · since v1.11 (Bridge)
01

More stable and reliable

All unsafe memory operations have been replaced with modern, safe alternatives. The emulator now uses automatic memory management everywhere, which means fewer unexpected crashes and more reliable gameplay — especially during long play sessions.

02

Cleaner, faster Lua engine

The old embedded Lua 5.1 engine (56 files) has been removed. FCEUX11 now uses a single, modern Rust-based Lua engine for all scripting. This means better performance, fewer compatibility issues, and a smaller installation size.

03

Easier to maintain and update

Over 15,000 lines of old, complex code have been cleaned up and modernized. Large files have been split into smaller, focused modules. This means bug fixes and new features can be delivered faster, and the emulator will continue to improve more smoothly.

04

12 languages, auto-detected

FCEUX11 ships in 12 languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Spanish, French, German, Vietnamese, Thai, Hindi (beta), and Arabic (beta with RTL layout). On first launch, it automatically picks the language that matches your Windows display language — no setup needed.
