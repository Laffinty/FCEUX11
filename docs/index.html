About

Introduction

FCEUX11 is a derivative of the FCEUX NES/Famicom emulator, actively maintained and optimized for Windows.

It preserves the core emulation accuracy of FCEUX while providing a modern, native Windows experience, including a Qt6-based user interface, multi-language support, and comprehensive debugging and TAS tooling.

What's new

v1.8 · Masonry

Released 2026-07-01 · since v1.7 (Cartograph)
01

All 174 mappers unified under modern C++ classes

Every supported NES/Famicom cartridge board now runs through a unified fceu11::Mapper subclass with auto-registration, replacing the legacy C-style function-pointer dispatch. Together with the v1.7 Cart class and v1.6 APU objectification, the entire core is now modern C++ — games load more predictably and the codebase is dramatically easier to maintain.

02

MMC3 family shares one base class

Twenty-three different MMC3-family mappers — the family behind Super Mario Bros 3, Kirby's Adventure, Mega Man 4–6, and hundreds more — now inherit from a single Mmc3BaseCart base class. Behavior stays consistent across the whole family and a single fix applies everywhere at once.

03

Expansion-audio chips unified

VRC7, MMC5, Namco 106 and Sunsoft 5B expansion-audio chips now use the same ExpansionAudio virtual interface introduced for VRC6 in v1.6. The audio path is cleaner, more predictable, and easier to extend when new chips are supported.

04

174 mapper byte-exact regression tests

Every supported mapper now has an automated byte-exact regression test that snapshots its internal state against a known-good golden file. Any future change that would shift a mapper's behavior is caught before release — the safety net behind every subsequent update.
