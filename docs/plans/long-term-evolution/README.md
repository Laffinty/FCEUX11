## 不变式（每个分项计划通用）

1. **内部逻辑检测保持 42P / 0F**，红灯即停。
2. **`pass_to_fail` 必须为 0**，出现即回滚 PR。
3. Instrument-first：改时序前先上探针（`docs/tech/precision.md` §4）。
4. known_fail / frozen baseline / savestate 金标更新 **须人工授权**。
5. 禁止无据 `known_limit`；禁止把 blocking 降级刷绿。
