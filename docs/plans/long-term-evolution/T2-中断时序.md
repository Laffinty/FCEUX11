## ⑧ kgmqa-037-cpu-int-2-nmi-brk-blargg

| 字段 | 值 |
|---|---|
| ROM | `blargg/cpu/cpu_interrupts_v2_2-nmi_and_brk.nes` |
| L2 同族 | `cpu_int_2/3/4/5`（NMI/BRK、NMI/IRQ、IRQ/DMA、branch-delay） |
| 错误码 | `0x01` |
| known_limit | polling only at instruction boundary (`x6502.cpp:515-579`); hijack/branch-delay not modeled |

### 现象（diag）

```
NMI BRK 00
27  36  00
26  36  00
...
```

NMI 与 BRK 交互周期对齐差 1；`cpu_int_3/4/5` 同族失败。

### 根因（结构性）

1. 中断仅在 **指令边界** 轮询（`x6502.cpp:515-579`）。
2. 未建模 **hijack**（中断劫持 BRK/IRQ 序列）。
3. 未建模 **分支延迟窗口** 内的 IRQ/NMI 采样。
