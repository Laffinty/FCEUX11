## 2. 改动点（每项独立提交、独立 gate、可回滚）

1. **stepper 逐周期接口**（`fceux11-core`）：每 CPU 周期返回调度点；指令完成语义与现有 FFI 兼容。未遂中断、页跨 dummy 读/写周期必须逐一建模（`cpu_dummy_writes_oam/ppu`、`cpu_exec_space_ppuio` 的前置）。
2. **scheduler 逐周期交错**：每 1 CPU 周期推进 3 PPU dot（PAL/Dendy 按各自比值，见 video_system 表）；**寄存器写在真实落点 dot 生效**（当前是整条指令跑完后才落——E1/E2 的直接根源）。保留 per-instruction 回退路径（scheduler 内部策略参数化，不出 configure 选项）。
3. **中断采样精确化**：NMI/VBL/IRQ 在精确 dot 采样（E4/E5）；`$2001` 重开写与 v 重建点的相对时序自然归位（E1）。
4. **DMA 节拍**：OAM DMA / DMC DMA 以 CPU 周期为节拍注入（每字节 1 周期读 + 1 写停顿，见现有 scheduler 注释），假读/假写触发真实寄存器副作用。
5. **探针对照协议（强制）**：本批每个子改动落地前后，必须按 v2.1.3 计划 §16.4 协议跑 3186_Mario_1.nes 对比：伪影帧复现率、分屏写落点分布、`$2001` 翻转点相对 pre-render 280-304 的落点。**无 probe 数据不得合入**（§15.7-1 红线）。

### 明确不在范围（本批不做）

- `$2006` 第二写 3-dot 延迟等五项写延迟的重新落地——批次 3 完成后**单独**按 Mesen2 语义 + probe 证据重评（§15.5 P1）；不得顺手捎带。
- 渲染期 `$2007` coarse-X 污染/双重递增（原改点 4）——同上，需要 Burai Fighter 类 ROM 的 probe 证据。
- PAL/Dendy 专属差异细化、MMC5 取指级 mapper、未公开指令全集（维持 v2.1.3 §8/§12 不变）。

## 3. 量化验收（发布门禁）

1. **blargg**：146 → **≥160 PASS**。硬性项：vbl_02/03/04/06/07/08/10、ppu_vbl_nmi、cpu_int_2..5、cpu_interrupts、instr_timing*、cpu_reset_regs、mmc3_4/v2_4；`vbl_nmi` 集成测试 5 项已知失败转绿（§10.2 遗留闭合）。预期余项：instr_v5/all 类（另行立项）、oam_stress/ppu_read_buffer/ppu_open_bus（批次 4/5）。
2. **伪影协议**（§16.4）：3186_Mario_1.nes 60 秒采集内伪影帧 **0**（对照：当前偶发卡片/logo 左移、残影竖条）；分屏写落点分布收敛到硬件窗口（hblank 内）；owner 实测 4 张原始截图场景复核。
3. **ctest**：41/41 保持；frame-diff / savestate-hash 基线按 §7.2 重生（预期差异源：写落点 dot 修正、中断进入时序——commit message 逐条列机理）。
4. **cargo**：全绿（不含 5 项 vbl_nmi——本批目标就是让它们转绿并删除该豁免记录）。
5. **性能**：bench_tolerance_test ≤ 基准 +2.5%（批次 2 后 nestest 基线 +6.6% 的教训：**逐周期调度是全计划最大性能风险**，§6 预估需重生 bench_baseline.json，owner 批准）；Release 60fps 门禁 1.5×。
6. **KIRA.nes** 240 帧无冻结（沿用既有 gate）。

## 4. 风险与缓解

- **性能**（最高风险）：逐周期派发每帧约 89k 次 stepper 调用。缓解：stepper 返回"距下一事件周期数"的批处理接口（事件驱动稀疏化）、热点路径零分配、基准门禁每子批必跑；回退开关保留 per-instruction 路径。
- **复杂度**：未遂中断/页跨 dummy 周期/dma 就绪位交互是经典深水区。缓解：以 blargg cpu_* 套件逐项驱动，一项一提交。
- **回归面**：写落点修正会改变全部 ROM 的帧哈希——按 §7.2 重生，commit message 列差异机理；KIRA 与 owner 症状 ROM 全量复测。

## 5. 里程碑切分（建议 4 个子批，各自独立 gate）

- **3a**：stepper 周期接口 + scheduler 逐周期交错（无中断语义变化，行为等价性用 frame-diff 零差异验证）。
- **3b**：写落点精确化（E1/E2——伪影协议为 gate）。
- **3c**：NMI/VBL/IRQ 精确采样 + 中断进入时序（E4/E5——blargg VBL/NMI 族为 gate）。
- **3d**：DMA 节拍 + dummy 周期（cpu_dummy_writes/exec_space 为 gate）+ mmc3_4/v2_4 校准。
