## 0. 摘要

v2.1.1.3 收口时，kagami matrix 唯一 blocking 项是 `blargg_ppu_read_buffer`（0x1B=27 FAIL）。该 test 本身有多个 sub-test（"Direct poke", "DMA with ROM", "DMA with 0000", "DMA with 0100", "DMA with …"），每个 sub-test 又有 "Hi"（sprite 0 hit 启用）和 "No-Hi"（sprite 0 hit 关闭）两个变体。v2.1.1.3 文档的"0x1B=27"指的是某一个 sub-test 的具体失败码。

本次 session 调查定位到一个 **NESdev spec 错误**：Rust PPU 的 `$2007` write（`Registers::write_data`）会在 `v < 0x3F00` 时更新 `vram_buffer = val`。NESdev wiki 明确说：

> "After reading from $2007, the value read is stored in this buffer. The next read from $2007 will return the value in the buffer, then update the buffer with the value at the new address. … **Writing to $2007 does not update the VRAM read buffer.**"

C++ engine（reference）`B2007`（`src/ppu.cpp:1085-1102`，new + old 两条路径均检查）**不**更新 `VRAMBuffer`，仅 `PPUGenLatch = V;` 写 open-bus。Rust PPU 与之不一致，是 stale v0.3.0 PPU 的实现残留。

修复后：
- ✅ cargo `fceux11-ppu` 14/14 open_bus tests pass（含 2 个新增的 NESdev 校准保护测试）
- ✅ ctest test 34 `rom_regression_rust_smoke` PASS（frame 2 = `0xb4a510ca` 不变）
- ✅ ctest test 35 `savestate_regression_rust_smoke` PASS（savestate MD5 不变）
- ⚠️ kagami `blargg_ppu_read_buffer` 单跑 result code 从 `0x1B` 变 `0x2F`（同一 ROM、不同 sub-test 失败）—— **matrix 1 blocking 仍存在**
- ⚠️ ctest test 31（kagami direct smoke）仍 FAIL（4P/8F 1 blocking）
- ⚠️ kagami-qa workflow R4 gate 仍 fail（Grade D）
- ⚠️ ctest test 33 仍 SKIP（Route C 不动）

**结论**：本次校准**严格 NESdev spec 校准**，无回归；但 1 个独立 sub-test 失败需 v2.1.1.x 后续 session 追。

## 1. 升级依据（Do-NOT 触发条件）

### 1.1 修复的 NESdev spec 校准性（**非"为测试改"**）

**修复内容**（commit v2.1.1.4）：`src/rust/crates/fceux11-ppu/src/registers.rs` 的 `Registers::write_data` 函数删除 `v < 0x3F00` 分支的 `self.vram_buffer = val;` 赋值。

**NESdev wiki 权威 spec**：

- `$2007` read：返回 `vram_buffer`，然后用 `vram[v]` 重新填充 `vram_buffer`，再 `v += inc`
- `$2006` second write：v = t，**下一次** $2007 read 触发 buffer 重新填充（`$2006` 写本身不直接刷新 buffer；这是 C++ engine `DummyRead` 机制的语义）
- `$2007` write：写 vram[v]，v += inc，**buffer 不变**

**C++ engine 对照**（`src/ppu.cpp:1085-1102` `B2007` newppu 路径）：

```c
if (newppu) {
    PPUGenLatch = V;                          // open-bus refresh
    opendecay_log_write(V);
    RefreshAddr = ppur.get_2007access() & 0x3FFF;
    CALL_PPUWRITE(RefreshAddr, V);            // vram[v] = V
    ppur.increment2007(ppur.status.sl >= 0 && ppur.status.sl < 241 && PPUON, INC32 != 0);
    RefreshAddr = ppur.get_2007access();
    // 注意：没有 VRAMBuffer = V
}
```

oldppu 路径（line 1119-1125）同样**没有** `VRAMBuffer = V;`，仅 `PPUGenLatch = V;`。

**Rust PPU 原实现**（line 487-489）：

```rust
if (v & 0x3FFF) < 0x3F00 {
    self.vram_buffer = val;   // ❌ NESdev 说不应更新
}
```

**根因定性**：stale v0.3.0 PPU 实现残留，**与硬件真值（NESdev wiki + C++ engine 双向对照）有偏差**。
