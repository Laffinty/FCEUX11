## 四、C-4 [MEDIUM] `SetSoundVariables` `SndRate==0` 早退 —— Skip

### 4.1 PLAN §四 C-4 假设

> "`SetSoundVariables` 在 `SndRate==0` 时仍执行 `nesincsize/soundtsinc` 的除法，产生 NaN/Inf。"

### 4.2 实地勘查（现状）

`src/sound.cpp:1164-1220` 函数体：

```cpp
void SetSoundVariables(void) {
  ...
  fhinc = PAL ? 16626 : 14915;   // * 2 CPU clock rate
  fhinc *= 24;

  if (FSettings.SndRate) {       // <-- 已有早退
    wlookup1[0] = 0;
    for (x=1; x<32; x++) { ... }
    ...
  } else {
    DoNoise=DoTriangle=DoPCM=DoSQ1=DoSQ2=Dummyfunc;
    return;                      // <-- 提前返回，先于 L1213 / L1219 的除法
  }

  MakeFilters(FSettings.SndRate);
  FCEU11_ExpRegionChanged(&GameExpSound);

  nesincsize = (int64)(((int64)1 << 17) * (double)(PAL?PAL_CPU:NTSC_CPU) / (FSettings.SndRate * 16));
  ...
  soundtsinc = (uint32)((uint64)(PAL?(long double)PAL_CPU*65536:(long double)NTSC_CPU*65536) / (FSettings.SndRate * 16));

```

**关键事实**：现有 `else { Do*=Dummyfunc; return; }`（L1203-1206）已经在 L1213/L1219 之前的控制流路径上拦截，不存在 PLAN 所描述的"仍执行除法"的可触发代码路径。

### 4.3 进一步分析

如果未来要按 PLAN "顶部早退"重构：

```cpp
if (!FSettings.SndRate) return;   // 提案
```

- 会**多跳过**：L1168-1169 的 `fhinc` 重算
- 影响：`FCEU_ResetVidSys()`（fceu.cpp:1087）→ 不带 `Sound(Rate>0)` 之前的路径下，`fhinc` 不会按 PAL/NTSC 切换重算

## 五、C-5 [HIGH] MMC3 mask 下溢 + MMC5fill nullptr 守卫 —— Skip

### 5.1 PLAN §四 C-5 假设（两条独立断言）

> **A. **`mmc3.cpp:316-318` `(prg>>13)-1` 在 `prg < 0x2000` 时减 1 = 0xFFFFFFFF → `PRGmask8[0]` 全 1 → 后续 `setprg8(V)` 越界。
>
> **B. **`mmc5.cpp:1037-1038` `MMC5fill_owner.get()` 在 `FCEU_gmalloc` 失败时返回 null → 后续 `FCEU_dwmemset(nullptr, ...)` 段错误。

### 5.2 实地勘查 —— **两条假设全不成立**

#### 5.2.A MMC3 —— "全 1"问题不成立

| 项 | 真相 |
|----|------|
| 三行语句 | `PRGmask8[0] &= (prg >> 13) - 1;` —— **用的是 `&=` 不是 `=`** |
| `prg` / `chr` 类型 | **signed `int`**（非 uint32/uint16） |
| `PRGmask8`/`CHRmask1`/`CHRmask2` 类型 | **`uint32_t[32]`**（非 uint8）—— 见 `bus.h:206-216` |
| 调用方 42 处 | 全部传 KiB 值（512/256/8/0） |
| 计算路径 `prg=512` | `(512 >> 13) - 1` → signed int `(0) - 1 = -1` → uint32 提升 `0xFFFFFFFF` → `&` 操作等价保留 |

**结论**：三行实际是 **no-op**（KiB 输入下永远保留原 ROM-derived mask）。即使按 PLAN "用 `=` 重写并设阈值"，对所有现有 42 个调用方会把 mask 全置 0，等于禁掉所有 MMC3 家族 mapper 的 bank 寻址。

#### 5.2.B MMC5 —— null 守卫不可达

`src/utils/memory.cpp:82-92`：

```cpp
void *FCEU_gmalloc(size_t size) {
  void *ret = ::operator new(size, std::nothrow);
  if (!ret)
    FCEU_abort("Error allocating memory!");    // <-- 失败时 abort()
  FCEU_MemoryRand((uint8*)ret, size, true);
  return ret;
}
```

`src/utils/memory.cpp:137-141`：

```cpp
void FCEU_abort(const char* message) {
  if (message) FCEU_PrintError("%s", message);
  abort();
}
```

`FCEU_gmalloc_unique`（`utils/memory.h:95-108`）把 `FCEU_gmalloc` 的返回值包成 `unique_ptr<uint8_t[], FceuMallocDeleter>`。**该 wrapper 在分配失败时不会观察到 null**，因为 `FCEU_gmalloc` 已 `abort()`。同 nothrow-但-abort 契约下：

| 位点 | 文件:行 |
|------|--------|
| WRAM | `mmc5.cpp:1030-1032` |
| MMC5fill | `mmc5.cpp:1037-1038`（PLAN 标的对象）|
| ExRAM | `mmc5.cpp:1039-1040` |
| NSF ExRAM | `mmc5.cpp:898-900` |

**全部不可达**。仅守 MMC5fill 没建立一致策略，且 mapper-init 函数返回 `void`、无法向上传播失败（也无统一的失败返回路径）。

#### 5.2.3 实际潜在线索

PLAN §四 C-5 没识别出但**同时存在**的真实问题：**MMC3 unit mismatch**。42 个调用方传 KiB，公式按 byte 移位：

| 行 | PLAN 意图 | 实际效果 |
|----|---------|---------|
| `mmc3.cpp:316` | "按 board 容量钳制 PRGmask8" | KiB 512 → `(512>>13)-1 = -1 → & 0xFFFFFFFF` = no-op |
| `mmc3.cpp:317` | "按 board 容量钳制 CHRmask1" | KiB 256 → `(256>>10)-1 = -1 → & ...` = no-op |
| `mmc3.cpp:318` | "按 board 容量钳制 CHRmask2" | KiB 256 → `(256>>11)-1 = -1 → & ...` = no-op |

可能**真实**的修复（保持 `&=` 同时按 KiB 修正移位）：

```cpp
PRGmask8[0] &= (prg >> 3) - 1;     // 8 KiB bank 计数
CHRmask1[0] &= chr - 1;            // 1 KiB bank 计数
CHRmask2[0] &= (chr >> 1) - 1;     // 2 KiB bank 计数
```

但**这是策略性修复**（会改变 bank 寻址语义、需要全 mapper_state regression + 8 例 CI test 双向回归 + cart_class_test 通过），且可能反向打破依赖 ROM-derived mask 的某些 mapper 实例。**不在 Phase C 范围。**

### 5.3 决策

**Skip C-5。** 双条 PLAN 假设全不成立：

- A. **MMC3 mask "全 1"问题不存在**（`&=` 是 no-op）
- B. **MMC5fill null 守卫不可达**（`FCEU_gmalloc` 走 abort）

如果未来要做：
- **真修 MMC3 容量钳制 unit-mismatch**：建独立策略 PR，独立 mapper 全矩阵 regression（178+ 例）+ `_phase_d_tests.h` 全跑
- **真修 MMC5 可恢复分配**：先把 `FCEU_gmalloc` 改成 nothrow + 返回 enum/expected 然后一次性覆盖 WRAM/MMC5fill/ExRAM/NSF ExRAM，再考虑 mapper-init void 接口 → 带 error code 接口
