### Cycle trace scaffolding

`build/v2.1_phase0/cycle_trace_v2.1.csv` — 30 frames × ~900 `Cpu::run` calls
each (≈ 27 000 rows). Schema:

```
frame,call_idx,cycles_arg,pc_after,cum_count,irq_low
0,0,89342,49164,4294967184,0
1,1,89342,49161,4294967168,512
...
```

Future Rust PPU scheduler work will diff a freshly captured CSV against this
file to localize per-frame cycle drift. The pre-Phase-7 cross-language diff
tool (`tools/cross_lang_diff.py`) is no longer applicable — only the Rust
CPU side exists after Phase 7 — but the CSV format is unchanged.

## 4. Reproducibility

The capture is reproducible to within the inputs below. Anything that
moves the baseline must be justified against this contract:

```powershell
# One-time:
.\scripts\setup_vcpkg.ps1
$env:VCPKG_ROOT = "$PWD\vcpkg"

# Build (matches what generated this baseline):
.\scripts\do_build.ps1 -Config Release

# Capture baseline:
powershell -ExecutionPolicy Bypass -File .\scripts\run_phase0_baseline.ps1

# Regenerate JSON:
powershell -ExecutionPolicy Bypass -File .\scripts\generate_phase0_json.ps1
```

Reproducing this run from scratch takes ~95 s on the development host
(build already present). A full rebuild is ~27 min.

## 5. What this baseline enables

| Phase | Gate this baseline supports |
|---|---|
| Phase 1 (Rust PPU core + pure-Rust tests) | Independent Rust-side test scaffold; this baseline stays untouched as the C++ reference |
| Phase 2 (FFI + dual-engine bridge)       | `FCEUX11_RUST_PPU` default-OFF must keep **all 33 ctests** and the **3/4 VBL subset** passing |
| Phase 3 (Unified scheduler + CPU micro-step) | `ppu_vbl_nmi` must flip from FAIL → PASS while `ppu_vbl_clear_time`, `scanline`, `scanline_a1` stay PASS |
| Phase 4 (PPU precision suite)            | Golden frame 0-pixel diff and `cycle_trace_v2.1.csv` row counts must match |
| Phase 5 (savestate compat bridge)        | `golden_savestate_test`, `savestate_regression_rust_smoke`, `mapper_byte_diff_rust_smoke` must remain PASS |
| Phase 6 (batch compat + perf)            | batch compat PASS rate (current 83.9%) must not regress; `cycle_trace_v2.1.csv` per-frame cycle sum must not grow > 5 % |
| Phase 7 (default-ON + C++ PPU retirement)| All of the above plus `FCEUX11_RUST_PPU=OFF` fallback still builds |
