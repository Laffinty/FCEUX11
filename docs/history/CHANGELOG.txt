================================================================================
FCEUX11 编年史（CHANGELOG）
================================================================================

说明
----
本文件以编年史方式记录 FCEUX11 自 fork FCEUX 2.6.6 以来的所有版本变更。
旧的详细构建文档（Construction Plan / Release Notes / Refactor Roadmap）与
归档的 legacy C++ 代码片段已不再保留，所有要点已浓缩至本表。

参考基线：fceux/fceux-2.6.6（upstream 标签 `legacy/fceux-2.6.6-base`）
许可证：GPLv2，原作者署名以最小必要限度保留
平台定位：Windows 11 独占；MSVC 2022 + vcpkg 单轨工具链（自 v0.2.1 起）

Phase 0–7（v0.1.0 之前）— 立项与初始重塑（2026-05）
================================================================================

Phase 0  基线与合规
  - GPLv2 衍生作品声明、版权审计、`legacy/fceux-2.6.6-base` 标签冻结。
  - 删除根目录过时文件（NEWS / INSTALL / LICENSE 重复项 / changelog.txt /
    install_deps.sh 等）。
  - 基线编译：MinGW-w64 GCC 16.1.0 + Qt5 + CMake 4.2.3，~1133 条警告。

Phase 1  标识层
  - `FCEU_NAME` → "FCEUX11"，版本宏与 About 窗口标题统一。
  - `APP_NAME = fceux11`；图标/manifest/资源更名为 fceux11。
  - readme.md 与 About 显示"基于 FCEUX 的衍生作品"。

Phase 2  构建系统
  - CMake 升至 3.28；C++ 标准强制 C++20。
  - 删除 Linux/macOS 分支，保留 MinGW 兼容；修复 `alloca` /
    `__forceinline` 宏冲突。

Phase 3  包管理
  - 引入 `vcpkg.json` 作为远期依赖管理；现阶段 MSYS2 pacman 并存。
  - `copy_dependencies.ps1` 增加 msys64 路径自动探测。

Phase 4  Qt6 UI
  - 全量迁移 Qt5 → Qt6：`QRegExp` → `QRegularExpression`，`QMutex(Recursive)`
    → `QRecursiveMutex` 等弃用 API 修复。
  - 暗/亮主题样式表草案；Segoe UI Variable 字体；C++20 `volatile` /
    lambda `this` 捕获修复。

Phase 5  Win11 平台
  - manifest 启用 PerMonitorV2 高 DPI、longPathAware、Unicode 宏。
  - 暗色模式检测、IFileDialog 评估、Snap Layouts 提示。

Phase 6  遗留代码清理
  - part 1：废弃 Win32/SDL 驱动、清理 CMake 债务、大规模跨平台宏清理。
  - part 2：低风险死代码删除（video.cpp / file.cpp / fceuWrapper.cpp /
    HelpPages.cpp）。
  - part 3：sdl-throttle 高精度睡眠重写、`unix-netplay.cpp` →
    `QtNetplay.cpp`、5 文件中风险宏清理、CMake 变量纯化。

Phase 7  Rust 重构准备
  - `src/rust/` 独立 Cargo crate，类型 staticlib。
  - 试点：`crc32fast` 替代 `src/utils/crc32.cpp` 中的 zlib 计算，
    通过 `fceux11_rust_crc32()` C ABI 暴露。

v0.2.x Rust 渐进式重构 —— 第一阶段：叶子模块（v0.2.2 – v0.2.11）
================================================================================
范式："Wrapper-Shim + Feature-Gate" —— C++ wrapper 在
`#ifdef FCEUX11_RUST_ENABLED` 时调用 Rust FFI，否则回退到原 C++ 实现。

v0.2.2  (2026-05-25)  MD5
  - `src/utils/md5.cpp` 改用 RustCrypto `md-5` crate（约 205 → 366 行 Rust，
    6 测试）。消除手写 MD5 维护负担，启用 SIMD。

v0.2.3  GUID
  - `src/utils/guid.cpp` 改用 `uuid` crate v4。`#[repr(C)] FceuGuid {
    data: [u8; 16] }`，thread-local 返回缓冲。消除 `rand()` 低质量随机性。

v0.2.4  General Utilities
  - `uppow2()` 改用 `u32::next_power_of_two`。作为端到端流水线
    （Cargo.toml → Rust → C wrapper → CMake → 测试）验证样板。

v0.2.5  Wave Audio Export
  - `src/wave.cpp`（~131 行）改用 Rust 安全文件 I/O；文件句柄由静态
    `Mutex<Box<File>>` 管理；采样率作为 FFI 参数传入。

v0.2.6  OS Utilities
  - `src/drivers/common/os_utils.cpp` 的 mkdir / mkpath / file_exists /
    msleep 改用 `std::fs` + `std::thread::sleep`。解耦 Win32 API，为未来
    跨平台打基础。

v0.2.7  Unicode Conversion
  - `src/utils/ConvertUTF.c`（~499 行）改用 Rust 标准库。slice 边界
    检查替代 2001 年风格手动指针算术，消除缓冲区溢出风险。约 1004 行
    Rust + 20 测试。

v0.2.8  TimeStamp（2026-05-29，发布说明）
  - `src/utils/timeStamp.cpp` 改用 `std::time::Instant`。C++ 侧保留
    `timeStampRecord` 类外壳，内部 readNew/toSeconds 转发到 Rust FFI，
    调用方零侵入。消除 Windows QPC/TSC 手动校准代码。
  - 软件版本号全面升至 v0.2.8（主窗口/About/Qt 翻译/CMake/vcpkg/Rust 元
    数据）。`cargo test` 42/42 通过。

v0.2.9  Profiler
  - `src/profiler.cpp` 的统计后端（`std::map<std::string, funcProfileRecord*>`）
    改用 Rust `HashMap`，通过 opaque `ProfilerHandle` 跨语言管理。C++
    `FCEU_PROFILE_FUNC` 宏与 RAII 对象保持不变。仅在
    `__FCEU_PROFILER_ENABLE__` 定义时编译。

v0.2.10  Audio Filter
  - `src/filter.cpp`（~209 行）改用 Rust。所有 static 局部状态
    （`acc`、`mrindex`、`mrratio` 等）封装在 opaque `FilterState`。
    FIR 系数表 `fir/*.h` 自动转换为 Rust `const` 数组 `fcoeffs.rs`。
    `NeoFilterSound` 验证了 C→Rust→C 函数指针回调可行。

v0.2.11  Palette
  - `src/palette.cpp`（~589 行）改用 Rust。`palette_ntsc` /
    `lo_levels` / `hi_levels` / `phases` 等大量静态数据用 Rust `const`
    数组表达。`FCEU_DrawNTSCControlBars` 验证了像素缓冲区（`*mut u8`
    + width/height + stride）FFI 边界。
  - 阶段总结：11 个模块、~3,714 行 Rust、62 测试全部通过，验证 CMake/
    Cargo 混合构建、手动 C ABI、Opaque Pointer、`#[repr(C)]` 等所有
    关键 FFI 范式。

不纳入 v0.2.x 的高风险模块（v0.3.x 候选）
================================================================================
  - 所有 Mapper（src/boards/*.cpp）：依赖 mapinc.h 宏系统
    （DECLFW / SFORMAT / setprg8）+ 函数指针注册，且位于核心模拟路径。
  - PPU（src/ppu.cpp）：每帧执行数万次，时序敏感。
  - CPU 6502（src/x6502.cpp）：指令周期必须精确匹配。
  - APU / Sound（src/sound.cpp）：与 MMC5/VRC6 扩展音频紧密耦合。
  - 输入设备核心（src/input.cpp）：与 Qt/SDL 事件循环耦合。
  - Memory 管理器（src/utils/memory.cpp）：FCEU_malloc/gmalloc 被全
