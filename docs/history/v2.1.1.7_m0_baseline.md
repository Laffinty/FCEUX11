## 7. 与 plan 文档的偏差（建议同步进 plan）

1. **ctest 数字口径**：实测为 **40 项（`-LE perf`）/ 41 项（全量）**，其中 1 项 SKIP（owner 批准的 Route C）。历史文档（一审所说的 "40/40"、父 plan 的 "39 PASS + 1 SKIP"）与实测不符；本 sub-plan 二审版已改为"以 M0 实测为准"。
2. **kagami gate 的执行方式**：Grade 只来自 subprocess 矩阵，且 `kagami-qa-runner` **不随 CMake 构建**（需先 `cargo build --release -p kagami-qa --bin kagami-qa-runner`，见 §3/§6），冻结基线入口是 `--baseline`（`Args::parse`，`src/rust/crates/kagami-qa/src/cli/args.rs:44-86`；无 `--matrix` flag）。plan §Step E gate 2 的前置步骤已据此补齐。
3. **Grade B 的语义**：是"9 项已知限制全部落在冻结基线内"，不是精度达标；作为 gate 时只能证明"无新增回归"。
4. **`kagami_qa_direct_smoke`（ctest #31）** 用的是 in-process direct 适配器，只覆盖 12 个 blargg 条目，**不产出 Grade**；Grade 只来自 §3 的 subprocess 矩阵。两者不可互相替代。
