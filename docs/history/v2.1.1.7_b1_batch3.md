## 3. 与 plan 的偏差 / 遗留

- 本批**只做 save 方向**：`FCEUPPU_LoadState()` 仍是 `TempAddr = TempAddrT; RefreshAddr = RefreshAddrT;`，即"载入后 Rust 状态恢复"尚未生效（第四批接线）。`TempAddrT` / `RefreshAddrT` 两个 scratch 暂留，避免本批提前改动 load 语义。
- chunk-31 的 29 个非 PST0/PST1 槽位在新引擎下没有对应物，按 plan 写中性常量 0。**若旧引擎路径下这些字段非 0，本批会一并改变其字节**——这正是 golden 需要 regen 的原因之一；第四/五批收口时若发现语义不可接受，可回退到"镜像 C++ 墓碑"策略。
- 第五批需要重生的 golden 有两处（本批已确认工具齐备）：
  1. `tests/fixtures/golden/golden_index.json`：`fceux11_golden_savestate_test --generate`（并配合 `--compare-layout` 证明 layout identical）；
  2. `tests/fixtures/golden_savestate_hashes.json`：kagami savestate regression runner 的 `--generate` 模式（`src/rust/crates/kagami-qa/src/lib.rs:252-315`）。
