# FCEUX11 v0.2.30 Release Notes

> **发布日期**：2026-06-07  
> **标签**：`v0.2.30`  
> **状态**：LTS 里程碑 / v0.2.x 系列收官  
> **前一版本**：v0.2.29

---

## 一、版本概述

v0.2.30 是 **v0.2.x 系列的最终 LTS 里程碑**。本版本不新增大规模 C++ → Rust 迁移，而是完成架构定型、核心抽象设计、文档沉淀与 FFI 边界冻结，为 **v0.3.x 全面核心渗透** 奠定坚实基础。

---

## 二、主要变更

### 2.1 新建 `fceux11-core` crate

- **路径**：`src/rust/crates/fceux11-core/`
- **定位**：核心模拟器逻辑的 Rust 新家。
- **当前内容**：
  - `state_file.rs` — savestate 文件格式管理（v0.2.29 引入）
  - `bus.rs` — 极简总线原型与性能基准
  - `traits.rs` — `Cpu`、`Ppu`、`Apu`、`Mapper` 核心 trait 定义
  - `state_recorder.rs` — 占位（v0.3.x 填充）

### 2.2 核心抽象设计 (`traits.rs`)

定义了 v0.3.x 将采用的组件化架构：

```rust
pub struct NesSystem<C: Cpu, P: Ppu, A: Apu, M: Mapper> {
    pub cpu: C,
    pub ppu: P,
    pub apu: A,
    pub mapper: M,
    pub wram: [u8; 0x800],
    pub prg_rom: Vec<u8>,
    pub chr_rom: Vec<u8>,
    pub cycle_count: u64,
}
```

关键设计决策：
- **System 拥有所有组件**：消除 C++ 分布式全局状态。
- **`&mut self` 统一调度**：避免 `Rc<RefCell<T>>` 运行时开销。
- **逐 tick 推进**：为 cycle-accurate 模拟预留接口。

### 2.3 总线模拟器原型 (`bus.rs`)

- 实现极简 `SimpleBus`（WRAM + PRG ROM）。
- `match`-based 地址解码，release 模式下可优化为跳转表。
- 包含微基准测试：`bench_simple_bus(1_000_000)` 在 debug 模式下 < 100 ms。
- 4 个单元测试验证 WRAM mirror、PRG ROM wrap、stub region 安全。

### 2.4 FFI 边界冻结

从 v0.2.30 开始：
- **180 个 FFI 函数** 的签名进入冻结期。
- 任何变更需提交 RFC 至 `docs/tech/`，并同步更新所有 C++ 调用方。
- cbindgen 自动生成的 `fceux11_rust.h`（2,358 行）作为唯一权威头文件。

### 2.5 文档沉淀

新增两份长期维护文档：

| 文档 | 路径 | 内容 |
|------|------|------|
| FCEUX11 Rust 重构手册 v1.0 | `docs/tech/rust_refactor_handbook_v1.0.md` | FFI 模式、Workspace 结构、测试策略、性能调优、v0.3.x 迁移指南 |
| Mapper Rust 化可行性研究报告 | `docs/tech/mapper_rust_feasibility.md` | 现状分析、4 种替代方案对比、Proc-Macro DSL 草案、风险评估、路线图 |

## 五、已知限制

1. **fceux11-core 当前仅为骨架**：`traits.rs` 定义了接口，无实际 C++ 调用方接入。
2. **StateRecorder 仍在 C++**：v0.3.x 将评估是否迁移。
3. **Mapper 系统未触及**：175 个 C++ Mapper 文件保持原样，v0.3.x 按可行性报告分批迁移。
