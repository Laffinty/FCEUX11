## 3. bmap[] 状态

`src/ines_bmap.h` 和 `src/unif_bmap.h` 中的 `bmap[]` 表**未标注 deprecated**。
`src/ines_init.cpp:30` 仍在活跃使用 `bmap[]` 进行 mapper 初始化查找。

> `docs/history/history.md` 声称 v1.9 已标记 `[[deprecated]]`，但实际代码中未找到该标注。
> `bmap[]` 在 registry 完全替代其功能前不能标记 deprecated。

**v2.0 前置工作**：评估 registry 是否已完全替代 `bmap[]` 的查找功能，若是，则标注 deprecated。
