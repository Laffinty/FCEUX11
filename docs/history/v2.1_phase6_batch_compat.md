### §6.1.b — Port 代码已落地（pending build verify）

**Edit**: `src/ppu_rust_bridge.cpp`

```cpp
void ppu_rust_bridge_cpu_read(uint32_t addr) {
    if (g_ppu_state == nullptr) return;

    // Phase 6.1.d (current intermediate state — A2002 port queued to
    // 6.1.d with mapper_mmc1 frame 0 gate; see NOTE in 6.1.b commit).
    return fceux11_ppu_cpu_read(g_ppu_state, static_cast<uint16_t>(addr));
}

void ppu_rust_bridge_cpu_write(uint32_t addr, uint8_t value) {
    if (g_ppu_state == nullptr) return;

    // Phase 6.1.b: B2000 rising-edge NMI-enable port.
    //   if (!(PPU[0] & 0x80) && (V & 0x80) && (PPU_status & 0x80))
    //       TriggerNMI2();  (C++ reference: src/ppu.cpp:958-962)
    if (addr == 0x2000) {
        const uint8_t old_ctrl = fceux11_ppu_get_register_state(g_ppu_state, 0);
        fceux11_ppu_cpu_write(g_ppu_state, static_cast<uint16_t>(addr), value);
        const uint8_t status = fceux11_ppu_get_register_state(g_ppu_state, 2);
        if (!(old_ctrl & 0x80) && (value & 0x80) && (status & 0x80)) {
            TriggerNMI2();
        }
    } else {
        fceux11_ppu_cpu_write(g_ppu_state, static_cast<uint16_t>(addr), value);
    }
    if (addr == 0x2007) {
        bridge_refresh_windows();
    }
}
```

**A2002 port** (sl240 cy340 抑制 + sl241 cy≤1 撤销) 当前 _未_ 落地 — 等 6.1.d 提交，伴 mapper_mmc1 frame 0 regression 测试 gate。

### §6.1.c — 工具链 fix (kagami-qa build error)

**Commit**: `dc59bc1 fix(kagami-qa): add missing use imports for golden write helpers in cfg-gated C-ABI entry modules`

发现的 bug: `kagami-qa` crate 在 `--features direct-adapter` 编译时无法解析 `write_golden_hashes_json` / `write_golden_savestate_hashes_json`，因为这两个函数定义在 `lib.rs` 顶层 module，但被 cfg-gated 模块的 `use` 语句未显式 import。在 Phase 5.3 §5.3.3 添加 `--generate` 模式时引入。

**修复**: 在 `rom_regression_entry` 与 `savestate_regression_entry` 模块内 `use crate::write_golden_{hashes,savestate_hashes}_json;` 两行。

**修复前 ctest 状态**: 之前 ctest 能 PASS 是因之前 cargo build cache 已经建立在“cfg gate 默认 off”时 → calls 不存在 → 函数不需要被引用。本次 cache 失效后 cargo 重新编译，重新引入 cfg gate 检查，函数解析失败。
