## 1. API 详细定义

### 1.1 `Cart::save_mapper_state()`

```cpp
// src/cart_class.h
namespace fceu11 {

class Cart {
public:
    // v1.8 §6.1: serialize mapper-internal state for byte-diff regression.
    //
    // Default: empty snapshot (base Cart / CartPlaceholder work as-is).
    //
    // Subclasses override to expose private registers / PRGptr / CHRptr.
    // Implementation MUST:
    //   - be noexcept (no allocation failures, no exceptions)
    //   - return little-endian binary, no padding
    //   - NOT include the 8-byte header (harness prepends it)
    //   - be deterministic: same mapper state → same bytes
    //
    // Vector resize is allowed (small ~256-512B typical).
    virtual std::vector<uint8_t> save_mapper_state() const noexcept;

    // v1.8 §6.1: restore from snapshot (for round-trip tests).
    // Default: no-op (legacy carts cannot restore).
    // Subclasses that override save_mapper_state should override this.
    virtual bool load_mapper_state(const std::vector<uint8_t>& state) noexcept;
};

} // namespace fceu11
```

### 1.2 默认实现（`src/cart_class.cpp`）

```cpp
std::vector<uint8_t> Cart::save_mapper_state() const noexcept {
    // Default: empty snapshot. The harness (mapper_byte_diff_test) will
    // detect size=0 and print [SKIP] for unmigrated boards (until Phase F).
    return {};
}

bool Cart::load_mapper_state(const std::vector<uint8_t>& /*state*/) noexcept {
    // Default: no-op. Subclasses override for round-trip tests.
    return false;
}
```

### 1.3 为何改用 `std::vector<uint8_t>` 而非 `void* + size_t`

| 维度 | `void* + size_t`（v1.7） | `std::vector<uint8_t>`（v1.8） |
|---|---|---|
| 缓冲区管理 | 调用方预分配，可能 buffer 不足 | 自动扩容，调用方零负担 |
| 错误处理 | 返回 0 = 失败（与"空快照"歧义） | size=0 = 显式空快照；失败抛异常（noexcept 不允许） |
| 168 子类实现负担 | 每个 override 需查 max_size + memcpy | 直接 `push_back` / `reserve` |
| 性能 | 单 memcpy（O(N)） | vector push_back 多次扩容（O(N) amortized，但 small buffer overhead） |
| 与 C++ 习惯 | C 风格 | 现代 C++ 习惯（v1.7 `Cart` 已用 `std::vector` 存 SaveGame） |

**性能影响**：168 个 mapper 的 `save_mapper_state` 单次调用 < 1 μs（小 vector），不构成热路径。`std::vector<uint8_t>` 的开销（24B vtable + size + capacity + heap）仅在 override 函数体内一次性分配。

## 2. Pack Helpers

### 2.1 定义（`src/cart_class.h`）

```cpp
namespace fceu11 {

// Pack helpers for save_mapper_state body.
// All multi-byte values are little-endian (LE), consistent with NES 6502
// internal representation and FCEUX11 on-disk savestate format.

inline void pack_u8(std::vector<uint8_t>& out, uint8_t v) noexcept {
    out.push_back(v);
}

inline void pack_u16(std::vector<uint8_t>& out, uint16_t v) noexcept {
    out.push_back(static_cast<uint8_t>(v & 0xFF));
    out.push_back(static_cast<uint8_t>((v >> 8) & 0xFF));
}

inline void pack_u32(std::vector<uint8_t>& out, uint32_t v) noexcept {
    out.push_back(static_cast<uint8_t>(v & 0xFF));
    out.push_back(static_cast<uint8_t>((v >> 8) & 0xFF));
    out.push_back(static_cast<uint8_t>((v >> 16) & 0xFF));
    out.push_back(static_cast<uint8_t>((v >> 24) & 0xFF));
}

inline void pack_u64(std::vector<uint8_t>& out, uint64_t v) noexcept {
    pack_u32(out, static_cast<uint32_t>(v & 0xFFFFFFFF));
    pack_u32(out, static_cast<uint32_t>(v >> 32));
}

inline void pack_i8(std::vector<uint8_t>& out, int8_t v) noexcept {
    out.push_back(static_cast<uint8_t>(v));
}

inline void pack_i32(std::vector<uint8_t>& out, int32_t v) noexcept {
    pack_u32(out, static_cast<uint32_t>(v));
}

// Array pack (固定长度 N 字节) — 与 v1.7 PoC 的 `pack_u8_array` 兼容
template <typename T, size_t N>
inline void pack_array(std::vector<uint8_t>& out, const T (&arr)[N]) noexcept {
    for (size_t i = 0; i < N; ++i) {
        pack_u8(out, static_cast<uint8_t>(arr[i]));
    }
}

// Variable-length byte array
inline void pack_bytes(std::vector<uint8_t>& out,
                       const uint8_t* data, size_t len) noexcept {
    out.insert(out.end(), data, data + len);
}

} // namespace fceu11
```

### 2.2 Helper 设计原则

| 原则 | 理由 |
|---|---|
| `inline`（header-only） | 让 MSVC / gcc 在 release build 展开调用，避免函数调用开销 |
| `noexcept` | 保持 mapper state 捕获路径无异常（异常 unwind 会污染 .bss） |
| 接受 `std::vector<uint8_t>&` 引用 | 避免每次调用返回新 vector（小函数优化） |
| 不引入 `<algorithm>` | `<vector>` 即可，header 更轻量 |

### 2.3 字节序

**所有 uint16/uint32/uint64 字段使用 little-endian (LE)**：
- 与 NES 6502 / x86 / FCEUX11 内部表示一致
- 与 v1.7 PoC 的 binary format 一致（`FMAP\0\0\0` magic 后的 uint32 LE 字段）
- `memcmp` 直接比较，无需转换

### 2.4 Helper 验证

每个 helper 写单测验证字节序与位模式：
- `pack_u32(0x12345678)` → `[0x78, 0x56, 0x34, 0x12]`
- `pack_u64(0x123456789ABCDEF0)` → `[0xF0, 0xDE, 0xBC, 0x9A, 0x78, 0x56, 0x34, 0x12]`

**测试位置**：`tests/core/cart_class_test.cpp` 新增 `test_pack_helpers` (Phase D)。

## 3. 二进制格式

### 3.1 Golden 文件总体结构

```
偏移    大小    字段
─────────────────────────────────────────────────────
0       8       magic = "FMAP\0\0\0" (8 bytes: 'F' 'M' 'A' 'P' 0 0 0 0)
8       4       version = 1 (uint32 LE) — 升级到 2 时加新字段
12      4       mapper_number (uint32 LE) — 与 bmap[] number 一致
16      4       body_size (uint32 LE) — 不含 16-byte header
20      ...     body bytes (由 Cart::save_mapper_state() 填充)
```

**总大小** = 16 + body_size。V1.7 设计的 16-byte header + body 模式保留；mapper_number 字段从 `body` 内部提升到 header 顶层（更便于 grep / 解析）。

### 3.2 v1.7 → v1.8 Header 差异

| 字段 | v1.7 | v1.8 | 备注 |
|---|---|---|---|
| magic (8B) | `"FMAP\0\0\0"` | `"FMAP\0\0\0"` | 不变 |
| version (4B) | 1 | 1 | 不变 |
| total_size (4B) | 含 header 总大小 | 移除（= 16 + body_size，可计算） | 简化 |
| mapper_number (4B) | 隐含（body 内第 0-3 字段） | 显式 | 便于 UNIF 板名解析 |
| body_size (4B) | 无 | 新增 | 便于反向读取（不用 stat 文件） |
| body (N B) | mapper-specific | mapper-specific | 内容不变 |

### 3.3 Per-Mapper Body 详细格式（首批 5 个典型范例）

v1.8 §6.4 列出 169 个 golden 的命名约定。每个 body 格式由对应 mapper 子类的 `save_mapper_state()` override 决定。

#### 3.3.1 NROM body (~32 bytes)

```cpp
// src/boards/nrom_cart.cpp
std::vector<uint8_t> NromCart::save_mapper_state() const noexcept {
    std::vector<uint8_t> out;
    out.reserve(32);
    pack_u32(out, 0);              // PRG bank 0 (固定)
    pack_u32(out, 0);              // PRG bank 1 (固定)
    pack_u32(out, 0);              // CHR bank 0 (固定)
    pack_u32(out, static_cast<uint32_t>(mirror()));  // mirror mode
    pack_u32(out, static_cast<uint32_t>(wram_size()));
    pack_u32(out, static_cast<uint32_t>(battery_wram_size()));
    // SaveGame buffer 前 16 字节
    if (!save_games().empty() && save_games()[0].bufptr) {
        pack_bytes(out, save_games()[0].bufptr,
                   std::min<size_t>(16, save_games()[0].buflen));
    } else {
        pack_bytes(out, nullptr, 16);  // 全 0
    }
    return out;  // ~32 bytes
}
```

```cpp
std::vector<uint8_t> Mmc1Cart::save_mapper_state() const noexcept {
    std::vector<uint8_t> out;
    out.reserve(128);
    pack_u32(out, mmc1_shift_register_);
    pack_u32(out, mmc1_prg_bank_[0]);
    pack_u32(out, mmc1_prg_bank_[1]);
    pack_u32(out, mmc1_chr_bank_[0]);
    pack_u32(out, mmc1_chr_bank_[1]);
    pack_u32(out, static_cast<uint32_t>(mirror()));
    pack_u32(out, mmc1_prg_mode_);
    pack_u32(out, mmc1_chr_mode_);
    pack_u32(out, mmc1_prg_mask_);
    pack_u32(out, mmc1_chr_mask_);
    pack_u64(out, mmc1_write_count_);
    // SaveGame buffer 前 32 字节
    if (!save_games().empty() && save_games()[0].bufptr) {
        pack_bytes(out, save_games()[0].bufptr,
                   std::min<size_t>(32, save_games()[0].buflen));
    } else {
        pack_bytes(out, nullptr, 32);
    }
    // PRGptr[2] + CHRptr[2] (4 pointers × 8B)
    pack_u64(out, reinterpret_cast<uint64_t>(prg_ptr_[0]));
    pack_u64(out, reinterpret_cast<uint64_t>(prg_ptr_[1]));
    pack_u64(out, reinterpret_cast<uint64_t>(chr_ptr_[0]));
    pack_u64(out, reinterpret_cast<uint64_t>(chr_ptr_[1]));

}
```

#### 3.3.3 MMC3 body (~256 bytes)

```cpp
// src/boards/mmc3_cart.cpp
std::vector<uint8_t> Mmc3Cart::save_mapper_state() const noexcept {
    std::vector<uint8_t> out;
    out.reserve(256);
    pack_u8(out, mmc3_cmd_);
    pack_array(out, dreg_buf_);     // 8 bytes
    pack_u8(out, a000b_);
    pack_u8(out, a001b_);
    pack_u8(out, irq_latch_);
    pack_u8(out, irq_count_);
    pack_u8(out, irq_enabled_ ? 1 : 0);
    pack_u8(out, irq_pending_ ? 1 : 0);
    pack_u32(out, mmc3_prg_mode_);
    pack_u32(out, mmc3_chr_mode_);
    pack_u32(out, prg_mask_8_[0]);
    pack_u32(out, prg_mask_8_[1]);
    pack_u32(out, chr_mask_1_[0]);
    pack_u32(out, chr_mask_1_[1]);
    pack_u64(out, mmc3_clock_total_);
    // SaveGame buffer 前 64 字节
    if (!save_games().empty() && save_games()[0].bufptr) {
        pack_bytes(out, save_games()[0].bufptr,
                   std::min<size_t>(64, save_games()[0].buflen));
    } else {
        pack_bytes(out, nullptr, 64);
    }
    // PRGptr[2] + CHRptr[8] (10 pointers × 8B = 80B)
    for (int i = 0; i < 2; ++i)
        pack_u64(out, reinterpret_cast<uint64_t>(prg_ptr_[i]));
    for (int i = 0; i < 8; ++i)
        pack_u64(out, reinterpret_cast<uint64_t>(chr_ptr_[i]));
    return out;  // ~256 bytes
}
```

### 3.4 Body 字段约定

每个 mapper 的 `save_mapper_state()` 实现遵循以下约定：

1. **不包含 mapper_number 字段**（在 header 中已显式）
2. **不包含 magic / version**（在 header 中）
3. **不包含 SaveGame 缓冲区长度**（固定前 N 字节，不足补 0）
4. **PRGptr / CHRptr 是 64-bit 地址**：v1.7 沿用此约定，便于 cross-platform；x64 build 下高 32 位总为 0
5. **padding 必须显式**：用 `pack_u8(out, 0)` 填充到 4-byte 对齐（v1.9 Chronicle 改为自然对齐）

### 4.2 命名约定

**规则**：
- 1 个 .bin 对应 1 个 iNES mapper number
- 多个 mapper number 共享同一 body 格式时（如 MMC3 变体），统一用 **最小编号** 命名
  - 例：mapper 4/12/37/44/45/47/49/52/74/114/115/116/118/119/165/205/245/249/250/254/406 共用 `mmc3.bin`（mapper 4 是 MMC3 标准）
- mapper 24/26 VRC6 共享 `vrc6.bin`
- mapper 19/210 Namco163 共享 `namco163.bin`

**冲突解决**：UNIF 风格 entry（256-547）不单独 .bin，沿用 iNES 编号对应的 .bin：
- 例：mapper 342 COOLGIRL 走 `coolgirl.bin`（即使 iNES 342 对应的 body 不严格等于 UNIF COOLGIRL）

| 类别 | .bin 文件数 |
|---|---|
| P0 (D) | 60 |
| P1 (E) | 74（不含 5 扩展音频） |
| P2 (F) | 30（多数 UNIF 风格共享 iNES 文件） |

> 169 = 222 iNES active − 53 共享 body 格式的派生（如 19 个 MMC3 变体共用 1 个 mmc3.bin）

## 5. 测试实现

### 5.1 主循环（`tests/core/mapper_byte_diff_test.cpp`）

```cpp
#include <cstdio>
#include <cstring>
#include <filesystem>
#include <fstream>
#include <vector>

#include "types.h"
#include "fceu.h"
#include "driver.h"
#include "state.h"
#include "cart_class.h"
#include "tests/boards/board_test_registry.h"  // Phase D 新增

static constexpr size_t HEADER_SIZE = 16;
static constexpr uint8_t MAGIC[8] = {'F', 'M', 'A', 'P', 0, 0, 0, 0};
static constexpr uint32_t VERSION = 1;

struct RomTestCase {
    const char* rom_path;      // tests/fixtures/mapper_<name>.nes
    const char* golden_name;   // tests/fixtures/golden_mapper/<name>.bin
    int         frames;        // 跑多少帧后捕获
};

// 全 169 mapper 的测试矩阵（Phase D-F 累积填充）
// Phase D 启动时含首批 60 个（P0）
static const std::vector<RomTestCase> kAllTests = {
    { "fixtures/mapper_nrom.nes",      "nrom",          60  },
    { "fixtures/mapper_uxrom.nes",     "uxrom",         60  },  // mapper 2
    { "fixtures/mapper_cnrom.nes",     "cnrom",         60  },  // mapper 3
    { "fixtures/mapper_mmc1.nes",      "mmc1",          90  },
    { "fixtures/mapper_mmc3.nes",      "mmc3",          120 },
    // ... 共 169 entries（Phase D-F 累积）
};

static bool captureMapperState(const char* golden_name,
                               std::vector<uint8_t>& out) {
    // 1. 从 fixtures/golden_mapper/<name>.bin 读取 header 获取 mapper_number
    std::filesystem::path header_path =
        std::filesystem::path("fixtures/golden_mapper") /
        (std::string(golden_name) + ".bin");
    if (!std::filesystem::exists(header_path)) {
        std::printf("[SKIP] %s: golden not generated yet (run --generate first)\n",
                    golden_name);
        return true;  // SKIP, exit 0
    }
    std::ifstream header_file(header_path, std::ios::binary);
    if (!header_file) return false;
    uint8_t header[HEADER_SIZE];
    header_file.read(reinterpret_cast<char*>(header), HEADER_SIZE);
    if (std::memcmp(header, MAGIC, 8) != 0) {
        std::fprintf(stderr, "[FAIL] %s: bad magic\n", golden_name);
        return false;
    }
    uint32_t version, mapper_number, body_size;
    std::memcpy(&version, header + 8, 4);
    std::memcpy(&mapper_number, header + 12, 4);
    std::memcpy(&body_size, header + 16, 4);
    if (version != VERSION) {
        std::fprintf(stderr, "[FAIL] %s: version %u (expected %u)\n",
                     golden_name, version, VERSION);
        return false;
    }

    // 2. 用 mapper_number 加载对应测试 ROM
    if (!loadRomByMapperNumber(mapper_number)) {
        std::fprintf(stderr, "[FAIL] %s: cannot load ROM for mapper %u\n",
                     golden_name, mapper_number);
        return false;
    }

    // 3. 跑 N 帧
    int target_frames = findTestCase(golden_name).frames;
    emulate_n_frames(target_frames);

    // 4. 捕获 mapper 状态
    if (!fceu11::g_cart) {
        std::fprintf(stderr, "[FAIL] %s: g_cart null\n", golden_name);
        return false;
    }
    out = fceu11::g_cart->save_mapper_state();
    if (out.size() != body_size) {
        std::fprintf(stderr, "[FAIL] %s: body size %zu (expected %u)\n",
                     golden_name, out.size(), body_size);
        return false;
    }
    return true;
}

static bool generateGolden(const RomTestCase& test) {
    std::vector<uint8_t> body;
    if (!captureMapperState(test.golden_name, body)) return false;

    // 读已有 header 提取 mapper_number
    std::filesystem::path golden_path =
        std::filesystem::path("fixtures/golden_mapper") /
        (std::string(test.golden_name) + ".bin");
    uint32_t mapper_number = 0;
    if (std::filesystem::exists(golden_path)) {
        std::ifstream f(golden_path, std::ios::binary);
        uint8_t existing_header[HEADER_SIZE];
        f.read(reinterpret_cast<char*>(existing_header), HEADER_SIZE);
        std::memcpy(&mapper_number, existing_header + 12, 4);
    }

    // 写新 header + body
    std::ofstream f(golden_path, std::ios::binary | std::ios::trunc);
    if (!f) return false;
    uint32_t version = VERSION;
    uint32_t body_size = static_cast<uint32_t>(body.size());
    f.write(reinterpret_cast<const char*>(MAGIC), 8);
    f.write(reinterpret_cast<const char*>(&version), 4);
    f.write(reinterpret_cast<const char*>(&mapper_number), 4);
    f.write(reinterpret_cast<const char*>(&body_size), 4);
    f.write(reinterpret_cast<const char*>(body.data()), body.size());

    std::printf("[GENERATE] %s: %u bytes written (mapper %u)\n",
                test.golden_name, HEADER_SIZE + body_size, mapper_number);
    return true;
}

static bool verifyGolden(const RomTestCase& test) {
    std::filesystem::path golden_path =
        std::filesystem::path("fixtures/golden_mapper") /
        (std::string(test.golden_name) + ".bin");
    if (!std::filesystem::exists(golden_path)) {
        std::printf("[SKIP] %s: golden not generated yet\n", test.golden_name);
        return true;
    }

    // 1. 读 golden
    std::ifstream f(golden_path, std::ios::binary);
    if (!f) return false;
    std::vector<uint8_t> golden((std::istreambuf_iterator<char>(f)),
                                 std::istreambuf_iterator<char>());
    if (golden.size() < HEADER_SIZE) return false;
    if (std::memcmp(golden.data(), MAGIC, 8) != 0) {
        std::fprintf(stderr, "[FAIL] %s: bad magic\n", test.golden_name);
        return false;
    }
    uint32_t version, body_size;
    std::memcpy(&version, golden.data() + 8, 4);
    std::memcpy(&body_size, golden.data() + 16, 4);
    if (version != VERSION) return false;
    if (golden.size() != HEADER_SIZE + body_size) return false;

    // 2. 捕获实时 mapper 状态
    std::vector<uint8_t> live;
    if (!captureMapperState(test.golden_name, live)) return false;
    if (live.size() != body_size) {
        std::fprintf(stderr, "[FAIL] %s: body size %zu (expected %u)\n",
                     test.golden_name, live.size(), body_size);
        return false;
    }

    // 3. memcmp body bytes
    int diff_offset = -1;
    for (size_t i = 0; i < body_size; ++i) {
        if (live[i] != golden[HEADER_SIZE + i]) {
            diff_offset = static_cast<int>(i);
            break;
        }
    }
    if (diff_offset >= 0) {
        std::fprintf(stderr,
            "[FAIL] %s: byte-diff at offset %d (live=0x%02X, golden=0x%02X)\n",
            test.golden_name, diff_offset,
            live[diff_offset], golden[HEADER_SIZE + diff_offset]);
        return false;
    }

    std::printf("[PASS] %s: %u bytes, byte-diff = 0\n",
                test.golden_name, body_size);
    return true;
}

int main(int argc, char** argv) {
    bool generate = (argc > 1 && std::strcmp(argv[1], "--generate") == 0);

    int total = 0, passed = 0, failed = 0, skipped = 0;
    for (const auto& test : kAllTests) {
        ++total;
        bool ok;
        if (generate) {
            ok = generateGolden(test);
            if (ok) ++passed; else ++failed;
        } else {
            // Distinguish SKIP from PASS
            std::filesystem::path golden_path =
                std::filesystem::path("fixtures/golden_mapper") /
                (std::string(test.golden_name) + ".bin");
            if (!std::filesystem::exists(golden_path)) {
                ++skipped;
                std::printf("[SKIP] %s: golden not generated yet\n",
                            test.golden_name);
            } else {
                ok = verifyGolden(test);
                if (ok) ++passed; else ++failed;
            }
        }
    }

    std::printf("\n--- mapper_byte_diff_test summary ---\n");
    std::printf("Total: %d  PASS: %d  FAIL: %d  SKIP: %d\n",
                total, passed, failed, skipped);

    if (failed > 0) {
        std::fprintf(stderr, "FAILED %d/%d mapper tests\n", failed, total);
        return 1;
    }
    return 0;
}
```

### 5.6 Round-trip 测试（load_mapper_state 验证）

除 byte-diff 外，每个 mapper 加一次 round-trip 测试（`test_<mapper>_load_save_roundtrip`）：

```cpp
// tests/boards/mapper_<N>_test.cpp
TEST(MapperLoadSaveRoundtrip, NROM) {
    if (!core_init()) FAIL();
    FCEUGI* gi = load_rom("fixtures/mapper_nrom.nes");
    ASSERT_NE(gi, nullptr);
    emulate_n(60);
    auto saved = fceu11::g_cart->save_mapper_state();
    emulate_n(60);  // 再跑 60 帧让状态变化
    bool loaded = fceu11::g_cart->load_mapper_state(saved);
    ASSERT_TRUE(loaded);
    auto reread = fceu11::g_cart->save_mapper_state();
    ASSERT_EQ(saved, reread);  // 两次 capture 必须完全一致
    core_shutdown();
}
```

### 6.3 golden 文件 commit 协议

1. **每个 Phase 第一次生成**：所有 golden 文件一次性 commit 到 git
2. **后续 mapper 字段变更**：更新 `save_mapper_state` 后必须重新跑 `--generate`，并将变更的 golden 文件 commit（diff 可读）
3. **不要**一次性 `git add tests/fixtures/golden_mapper/`：只 stage 实际变更的 .bin 文件
4. CI 检查：每次 PR 必须 verify 模式 169/169 PASS 才允许合入

## 9. 风险与缓解

| 风险 | 可能性 | 影响 | 缓解 |
|---|---|---|---|
| `save_mapper_state` 171 override 编译开销超 +10% | 中 | CI 时间膨胀 | pack helpers inline + noexcept |
| body 字段顺序不一致导致 golden 漂移 | 中 | 169 golden 全部重生成 | Phase A 文档固化字段顺序；`--generate` 一次性提交 |
| `std::vector` heap 分配在 hot path | 低 | 测试偶发超时 | 169 mapper 测试是冷路径 |
| PRGptr / CHRptr 64-bit 跨平台差异 | 低 | x86 vs ARM golden 不一致 | FCEUX11 限定 x64 build；与 v1.7 PoC 一致 |
| golden 文件 50 KiB 增加 git repo 大小 | 低 | repo +0.05% | 可接受；与 v1.5/v1.6 一致 |
| `load_mapper_state` 默认返回 false 导致 round-trip 跳过 | 中 | round-trip 测试覆盖不全 | Phase D 末强制所有 PoC override `load_mapper_state` |
