## 3. Deferred items (handed to v1.8 Masonry §8.2)

1. **166 un-migrated boards → Cart subclass batch migration**
   - Only 4 mappers are Cart subclasses today (NROM/MMC1/MMC3/VRC6 PoCs).
   - `create_cart_for_mapper` returns `nullptr` for the other 166.
   - v1.8 §8.4 will replace the switch with the `MapperEntry` auto-register table.

2. **PoC cart `on_close()` does not free WRAM/CHRRAM**
   - The v1.7 factory block overwrites `info->Close = CartInfo_CloseForward`,
     so the legacy `GenMMC1Close` / `GenMMC3Close` / `GenMMC3Close` paths are
     bypassed.
   - 166 un-migrated boards still free WRAM/CHRRAM correctly because they
     assign `info->Close` to `GenMMC1Close` / etc. before the v1.7 factory
     block runs.
   - Per-load leak: 8 KiB WRAM (MMC1 / MMC3) + 8 KiB CHRRAM (MMC3). Only
     material in long sessions that load many ROMs.

3. **Other MMC3 variants not covered**
   - Mapper 12 / 37 / 44 / 45 / 47 / 49 / 52 / 74 / 114 / 115 / 116 / 118 /
     119 / 165 / 205 / 245 / 249 / 250 / 254 / 406 use the same
     `GenMMC3_Init` but with mapper-specific Power overrides.
   - v1.8 §8.2 will either add more PoC subclasses or introduce a
     `Mmc3BaseCart` template with mapper-specific override hooks.

4. **`Cart::save_mapper_state()` API + `mapper_byte_diff_test` body capture**
   - v1.7 `mapper_byte_diff_test` still prints [SKIP] for body byte-diff.
   - Golden generation requires a Cart-side snapshot API that captures mapper
     registers / private fields in a stable binary format.
   - v1.8 §8.2 will introduce the API; goldens generated then.

5. **`readme.md` / `README.md` / `docs/BuildGuide.md` / `docs/index.html`**
   - Still advertise "v1.5 Prism" in user-facing docs.
   - Defer to a follow-up "docs: v1.7 release" commit (not part of Phase G
     per the v1.7 build plan §10.8 — that section does not list these
     updates).

## 4. v1.7 ↔ v1.8 Masonry handoff interface

The Cart / Mapper / MirrorMode interface stabilized in v1.7 is the contract
v1.8 will consume:

- **`fceu11::Cart`** — base class; concrete subclasses implement
  `on_power` / `on_reset` / `on_close`.
- **`fceu11::Mapper : Cart`** — thin base; holds `Bus*` via `attach_bus`.
- **`fceu11::create_cart_for_mapper(uint32_t, Bus&)`** — factory.
  v1.8 §8.4 will replace this function with a static `MapperEntry`
  auto-register table, but the signature stays.
- **`fceu11::MirrorMode`** — enum class with `Horizontal` / `Vertical` /
  `Mode0` / `Mode1`. Legacy `MI_*` macros retained as `int` aliases.
- **`Cart::install_expansion_audio(Apu&) noexcept`** — virtual, default
  no-op. v1.8 §8.2 batch 2+ will override this in Vrc7Cart / Mmc5Cart /
  N106Cart / FdsCart / Mapper69Cart subclasses.
