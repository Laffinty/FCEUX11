1. **§2 MapperEntry 注册表必须 Phase C 一次性引入并验证**。不能在 board 子类化过程中逐步替换 `bmap[]` 数组——每次替换都触发 LAYOUT 重排。

**模板 A**（与 v1.7 NROM / VRC6 / MMC1 / MMC3 PoC 一致 — Strategy A）：

// src/boards/<mapper>_cart.cpp  (or appended to existing <mapper>.cpp)
#include "boards/<mapper>_cart.h"

namespace fceu11 {

void <Mapper>Cart::on_power() noexcept {
    // Swap info->Power to legacy <Mapper>_Power then call it (Strategy A).
    if (!currCartInfo) return;
    void (*saved)(void) = currCartInfo->Power;
    currCartInfo->Power = <Mapper>_Power;
    currCartInfo->Power();
    currCartInfo->Power = saved;
}

void <Mapper>Cart::on_reset() noexcept {
    // Call legacy reset helper (e.g., <Mapper>RegReset) directly.
    <Mapper>RegReset();
}

    // See §1.3: unified WRAM/CHRRAM release + IRQ hook cleanup.
    release_mapper_resources_<mapper_no>();
}

} // namespace fceu11

### 1.3 PoC `on_close()` 统一释放方案（v1.7 遗留）

v1.7 Phase G handoff §3.2 记录：4 个 PoC 的 `on_close()` **不释放** WRAM / CHRRAM（每次 game load 8 KiB 泄漏）。v1.8 统一方案：

```cpp
// src/boards/_cart_helpers.h  (Phase D 引入)
namespace fceu11 {

// Unified release for the 4 legacy board resources.
// Called by every Cart subclass on_close().
void release_mapper_resources(uint32_t mapper_no) noexcept;

} // namespace fceu11

// src/boards/_cart_helpers.cpp  (Phase D 引入)
namespace fceu11 {

// Switch-free dispatch table indexed by mapper_no.
// Avoids the static-init-order footgun of MapperEntry (§2.2).
static void (*const kMapperCloseFuncs[256])(void) = {
    /*[0]=*/&NROM_Close, /*[1]=*/&GenMMC1Close,
    /*[4]=*/&GenMMC3Close, /*[24]=*/&VRC6Close, ...
};

void release_mapper_resources(uint32_t mapper_no) noexcept {
    if (mapper_no < 256 && kMapperCloseFuncs[mapper_no]) {
        kMapperCloseFuncs[mapper_no]();
    }
    GameHBIRQHook = nullptr;  // Always drop; cheap.
}

} // namespace fceu11
```

**约束**：
- 仅覆盖 v1.8 范围内的 mapper（166 + 5 扩展音频）
- 不重新设计 `GenMMC1Close` / `GenMMC3Close` 等现有函数体（保持 byte-identical）
- `GameHBIRQHook = nullptr` 总是执行（即使 mapper_no 不在表内），防漏

### 1.4 其他 MMC3 变体（Mapper 12 / 37 / 44 / ...）→ Mmc3BaseCart 派生

v1.7 仅 PoC Mapper 4（MMC3 标准）。其他 19 个 MMC3 衍生 mapper（Mapper 12 / 37 / 44 / 45 / 47 / 49 / 52 / 74 / 114 / 115 / 116 / 118 / 119 / 165 / 205 / 245 / 249 / 250 / 254 / 406）走 `currCartInfo` 兼容层。

**统一方案**：

```cpp
// src/boards/mmc3_base_cart.h  (Phase E 引入)
namespace fceu11 {

class Mmc3BaseCart : public Mapper {
public:
    explicit Mmc3BaseCart(Bus& bus, uint32_t mapper_no) noexcept {
        attach_bus(bus);
        mapper_number_ = mapper_no;

    void on_power() noexcept override;     // dispatches to M<N>Power by mapper_no
    void on_reset() noexcept override;     // always MMC3RegReset
    void on_close() noexcept override;     // release + GameHBIRQHook null

} // namespace fceu11
```

**派生子类**（仅 override mapper-specific 部分）：

```cpp

class Mapper12Cart : public Mmc3BaseCart {
public:
    explicit Mapper12Cart(Bus& bus) noexcept : Mmc3BaseCart(bus, 12) {}

    // No other override needed.

```

**19 个 MMC3 变体** 仅需 19 行派生 .h 文件 + 一个 `kMmc3PowerFuncs[256]` dispatch 表。Phase E 单批 commit。

## 2. MapperEntry 自动注册表（Roadmap §8.4）

### 2.1 现状

`src/ines.cpp:320` 的 `BMAPPINGLocal bmap[]` 数组是 v1.0 函数指针表：

```cpp
typedef struct {
    const char *name;
    int32 number;
    void (*init)(CartInfo *);
} BMAPPINGLocal;

BMAPPINGLocal bmap[] = {
    {"NROM",                  0, NROM_Init},
    {"MMC1",                  1, Mapper1_Init},
    /* ...235 entries... */
};
```

v1.7 的 `create_cart_for_mapper()` switch 是临时替代品。v1.8 用 `MapperEntry` 静态表替代 switch。

### 2.2 MapperEntry 设计

```cpp
// src/boards/registry.h  (Phase C 引入)
namespace fceu11 {

struct MapperEntry {
    uint32_t mapper_number;
    const char* name;
    void (*legacy_init)(CartInfo*);                        // for compat layer
    std::function<std::unique_ptr<Mapper>(Bus&)> factory;  // for v1.8+
};

const MapperEntry* find_mapper(uint32_t number) noexcept;
const MapperEntry* find_mapper_by_name(const char* name) noexcept;  // UNIF support

} // namespace fceu11
```

**静态注册机制**（避免 `std::map` 运行时构造）：

```cpp
// src/boards/registry.cpp  (Phase C 引入)
namespace {

struct MapperEntryRegister {
    MapperEntryRegister(const MapperEntry& entry) {
        // Append to global list. Init order guaranteed by C++11 magic statics.
        // Max 256 entries; crash if exceeded.
        fceu11::kMapperRegistry[entry.mapper_number] = entry;
    }
};

} // namespace

// Each board file declares a static instance:
// src/boards/nrom.cpp:
namespace {
static MapperEntryRegister kNromRegister{
    { 0, "NROM", &NROM_Init,
      [](Bus& bus) { return std::make_unique<NromCart>(bus); } };
}

// src/boards/mmc1.cpp:
namespace {
static MapperEntryRegister kMmc1Register{
    { 1, "MMC1", &Mapper1_Init,
      [](Bus& bus) { return std::make_unique<Mmc1Cart>(bus); } };
}

// ... (one per board file; total 171 static instances)
```

**静态初始化顺序保证**：
- 每个 `kXxxRegister` 在该 board TU 第一次被引用时被构造（C++11 magic statics）
- `kMapperRegistry[256]` 是函数内 static 数组（Meyers singleton），构造顺序未定义但**与 register 实例独立**
- `find_mapper()` 触发首次 `kMapperRegistry` 构造，之后所有 board 文件被引用时自动填充

**UNIF 板名查找**：

```cpp
const MapperEntry* find_mapper_by_name(const char* name) noexcept {
    // O(N) linear scan; UNIF board count is small (~50 boards).
    for (const auto& entry : kMapperRegistry) {
        if (entry.name && std::strcmp(entry.name, name) == 0)
            return &entry;
    }
    return nullptr;
}
```

### 2.3 与 `bmap[]` 的过渡

**Phase C 步骤**：
1. 引入 `registry.h` / `registry.cpp`

## 5. FceuMallocPtr RAII 全量采纳（Roadmap §8.3）

### 5.1 审计范围

171 个 board 文件 + `src/fds.cpp` + `src/cart.cpp` 中的 `malloc()` / `free()` / `FCEU_gmalloc()` / `FCEU_gfree()` 调用。

**当前状态**（v1.7 末态）：
- `src/boards/vrc6.cpp` 等 ~10 个文件已用 `FceuMallocPtr` RAII（v0.3.6 起）
- 其余 ~160 个文件仍裸 `malloc()` / `free()`

### 5.2 替换模板

```cpp
// Before:
static uint8* WRAM = NULL;
WRAM = (uint8*)FCEU_gmalloc(WRAMSIZE);
// ... later in Close:
if (WRAM) { FCEU_gfree(WRAM); WRAM = NULL; }

// After:
static FceuMallocPtr WRAM_owner;  // RAII: FCEU_gfree on destruction
WRAM_owner = FCEU_gmalloc_unique(WRAMSIZE);
uint8* WRAM = WRAM_owner.get();
// No Close needed: WRAM_owner.reset() in on_close releases.
```

### 5.3 时机：Phase H 收尾（与 doc 刷新 + tag 一起）

**理由**：
- 纯机械替换，热路径无影响
- 但替换会改变 struct 布局（`FceuMallocPtr` 大小 vs `uint8*`），可能轻微 layout shift
- 放在最后做，不污染 §1/§2/§3/§4 的 bench baseline

### 5.4 验收（§5）

- `src/boards/*.cpp` + `src/fds.cpp` 零裸 `malloc()` / `free()`
- 全部改用 `FceuMallocPtr` / `FceuMallocPtr_array` RAII
- `FCEU_amalloc` 调用点加 `[[nodiscard]]`
- `ctest -LE perf` 21/21 PASS（不变）
- `bench_tolerance_test` 偏差 ≤ +0.5%（机械替换，期望无显著变化）

## 6. Cart::save_mapper_state() API + mapper_byte_diff_test body byte-diff

### 6.1 API 签名

```cpp

namespace fceu11 {

class Cart {
public:
    // v1.8 §6.1: serialize mapper-internal state for byte-diff regression.
    // Default implementation returns empty snapshot (legacy carts work as-is).
    // Subclasses override to expose private registers / PRGptr / CHRptr.
    virtual std::vector<uint8_t> save_mapper_state() const noexcept;

    // v1.8 §6.1: restore from snapshot (for round-trip tests).
    virtual bool load_mapper_state(const std::vector<uint8_t>& state) noexcept;
};

} // namespace fceu11
```

### 6.2 二进制格式

```cpp
// src/cart_class.cpp  (Phase D 引入)
std::vector<uint8_t> Cart::save_mapper_state() const noexcept {
    // Default: empty snapshot. Override per-mapper to include private state.
    return {};
}

namespace fceu11 {

// Per-mapper snapshot format (little-endian):
//   [0..3]   uint32 mapper_number
//   [4..7]   uint32 body_size (excluding header)
//   [8..N]   mapper-specific body (registers, ptrs, IRQs, etc.)
//
// Cart::save_mapper_state() returns the body bytes only; the harness
// (mapper_byte_diff_test) prepends the header from Cart::mapper_number().
} // namespace fceu11
```

### 6.3 每个 mapper 子类的 override

```cpp
// src/boards/mmc3_cart.cpp  (Phase D 扩展)
std::vector<uint8_t> Mmc3Cart::save_mapper_state() const noexcept {
    std::vector<uint8_t> out;
    out.reserve(64);
    // Use pack helpers from cart_class.h
    pack_u8(out, MMC3_cmd);
    pack_u8_array(out, DRegBuf, 8);
    pack_u8(out, A000B);
    pack_u8(out, A001B);
    pack_u8(out, IRQLatch);
    pack_u8(out, IRQCount);
    pack_u8(out, IRQa);
    pack_u32(out, PRGmask8[0]);
    pack_u32(out, CHRmask1[0]);
    // ... etc
    return out;
}
```
