### 0.2 原则

1. **纯代码移动（carryover 部分）**：延续 v1.12 原则，拆分操作零行为变更
2. **安全语义变更（Purify 原始项）**：`malloc→unique_ptr` 等语义替换需逐项回归验证
3. **布局兼容性**：任何涉及 `alignas` / 类布局的操作必须 `static_assert` 断言
4. **编译门禁**：`cmake --build build --config Release` 零错误零警告（`/W4 /WX`）
5. **性能不退步**：核心模拟文件（ppu/movie）每批次拆分后跑 bench；GUI 拆分跑综合 bench
