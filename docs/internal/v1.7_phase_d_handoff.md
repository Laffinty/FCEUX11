## 2. What Phase D must do

Phase D virtualizes mapper lifecycle and adds savestate hooks. **It is intentionally infrastructure-only**: the factory returns `nullptr` for every mapper so behavior does not change yet. Phase E/F will override the factory for NROM/MMC1/MMC3 PoC subclasses.

### 2.1 Lifecycle call flow today

```
PowerNES() / ResetNES() / CloseGame()
  -> GameInterface(GI_POWER / GI_RESETM2 / GI_CLOSE)
     -> iNESGI() / UNIFGI()
        -> iNESCart.Power() / Reset() / Close()   (or UNIFCart)
           -> board function pointer set by MapperNN_Init()
```

Relevant files:
- `src/fceu.cpp:957-1104` — `ResetNES()`, `PowerNES()`, `fceu11::CloseGame()`
- `src/ines.cpp:99-116` — `iNESGI()`
- `src/unif.cpp:553-571` — `UNIFGI()`
- `src/cart.h` — `CartInfo` struct, `CartInfo_PowerForward/ResetForward/CloseForward`
- `src/cart.cpp:66-79` — forwarding function definitions
- `src/cart_class.h:47-146` — `fceu11::Cart` class with pure virtual `on_power/on_reset/on_close`

### 2.2 What already works from Phase B/C

`CartInfo::clear()` already installs the forwarding functions:

```cpp
// src/cart.h
void clear(void) {
    Power = CartInfo_PowerForward;
    Reset = CartInfo_ResetForward;
    Close = CartInfo_CloseForward;
    // ...
}
```

`CartInfo_PowerForward` already routes to `cart_obj`:

```cpp
// src/cart.cpp
void CartInfo_PowerForward(void) {
    if (currCartInfo && currCartInfo->cart_obj)
        currCartInfo->cart_obj->on_power();
}
```

So Phase D only needs to:
1. Create a factory that can return concrete `Cart` subclasses.
2. Wire the loaders to call the factory and install the forwarding functions when a cart is returned.
3. Add savestate hooks in `state.cpp`.

## 3. Step-by-step implementation

### Step 1: Add factory and ownership helpers (`src/cart_class.h` / `src/cart_class.cpp`)

#### `src/cart_class.h`

Inside `namespace fceu11`, after the `Cart` class declaration and before `extern Cart* g_cart;`, add:

```cpp
// Phase D factory: create a concrete Cart subclass for a given iNES mapper
// number. Phase D stub returns nullptr for all mappers; Phase E/F override
// for NROM (0), MMC1 (1), and MMC3 (4).
std::unique_ptr<Cart> create_cart_for_mapper(uint32_t mapper_no, Bus& bus);

// Take ownership of a newly-created cart and update the global g_cart pointer.
// Passing nullptr restores g_cart to the no-op placeholder.
void assign_cart(std::unique_ptr<Cart> cart);
```

You will need to include `<memory>` in `cart_class.h` if it is not already included.

#### `src/cart_class.cpp`

In the anonymous namespace, add an owner alongside the placeholder:

```cpp
namespace {

class CartPlaceholder : public fceu11::Cart {
public:
    void on_power() noexcept override {}
    void on_reset() noexcept override {}
    void on_close() noexcept override {}
};

CartPlaceholder g_cart_placeholder;
std::unique_ptr<fceu11::Cart> g_cart_owner;

} // namespace
```

Implement the helpers:

```cpp
namespace fceu11 {

// existing: Cart* g_cart = &g_cart_placeholder;

std::unique_ptr<Cart> create_cart_for_mapper(uint32_t /*mapper_no*/, Bus& /*bus*/) {
    // Phase D: infrastructure only. All mappers keep using the legacy
    // CartInfo function pointers. Phase E/F will add switch cases here
    // for NROM/MMC1/MMC3.
    return nullptr;
}

void assign_cart(std::unique_ptr<Cart> cart) {
    g_cart_owner = std::move(cart);
    g_cart = g_cart_owner ? g_cart_owner.get() : &g_cart_placeholder;
}

} // namespace fceu11
```

**Important**: Keep `Cart* g_cart` as the public raw pointer. Do not remove it.

### Step 4: Add savestate hooks (`src/state.cpp`)

#### `on_save_pre` hook

In `FCEUSS_SaveMS()` around line 347, you will see:

```cpp
	if (SPreSave) SPreSave();
	addSformatChunk(0x10, SFMDATA);
	if (SPostSave) SPostSave();
```

Add immediately before `if (SPreSave) SPreSave();`:

```cpp
	// v1.7 Phase D: give the current cart a chance to prepare state before
	// the SFMDATA chunk is serialized. Default implementation is a no-op.
	if (currCartInfo && currCartInfo->cart_obj)
		currCartInfo->cart_obj->on_save_pre();
```

#### `on_load_post` hook

In `FCEUSS_LoadFP()` around line 597-601, you will see:

```cpp
	if (ret)
	{
		FCEUPPU_LoadState(version);
		FCEUSND_LoadState(version);
		ret = FCEUMOV_PostLoad();
	}
```

Change it to:

```cpp
	if (ret)
	{
		FCEUPPU_LoadState(version);
		FCEUSND_LoadState(version);
		ret = FCEUMOV_PostLoad();
		// v1.7 Phase D: notify the current cart after a successful load.
		// Default implementation is a no-op, so savestate compatibility is
		// unchanged.
		if (ret && currCartInfo && currCartInfo->cart_obj)
			currCartInfo->cart_obj->on_load_post();
	}
```

`state.cpp` already has access to `currCartInfo` because `src/cart.h` is included transitively. If not, add `#include "cart.h"`.

#### `test_on_load_post_trigger_sequence`

Replace the stub with:

```cpp
void test_on_load_post_trigger_sequence(TestContext& ctx) {
    if (!core_init()) {
        FCEU11_EXPECT(ctx, false, "core_init failed");
        return;
    }

    FCEUGI* gi = load_rom("fixtures/nestest.nes");
    if (!gi) {
        FCEU11_EXPECT(ctx, false, "failed to load nestest.nes");
        core_shutdown();
        return;
    }

    // Run a few frames so the savestate has something to serialize.
    emulate_n(10);

    // Install our counting cart into the legacy CartInfo.
    CountingTestCart test_cart;
    fceu11::Cart* old_cart_obj = currCartInfo->cart_obj;
    currCartInfo->cart_obj = &test_cart;

    // Save state to a temp file.
    const char* tmp_state = "cart_class_test_tmp.fcs";
    bool saved = FCEUSS_Save(tmp_state, false);

    // on_save_pre should have been triggered during save.
    FCEU11_EXPECT(ctx, saved, "FCEUSS_Save succeeded");
    FCEU11_EXPECT(ctx, test_cart.on_save_pre_count == 1,
                  "on_save_pre triggered exactly once during save");

    // Load the state back.
    bool loaded = FCEUSS_Load(tmp_state, false);
    FCEU11_EXPECT(ctx, loaded, "FCEUSS_Load succeeded");
    FCEU11_EXPECT(ctx, test_cart.on_load_post_count == 1,
                  "on_load_post triggered exactly once after successful load");

    // Restore the previous cart_obj so cleanup does not touch our stack cart.
    currCartInfo->cart_obj = old_cart_obj;

    // Clean up temp file.
    std::remove(tmp_state);

    core_shutdown();
}
```

**Note**: `FCEUSS_Save` and `FCEUSS_Load` are declared in `src/state.h`, which is already included by `test_helpers.h`. `std::remove` needs `<cstdio>` (already included).

Update the `main()` print message to say "Phase D: on_save_pre/on_load_post tests active; Phase E/F tests still [SKIP]" or similar.

## 6. Known issues and constraints

1. **Bench regression**: `bench_full_frame` is already ~+3.5-4% vs the v1.5 baseline due to Phase B/C link-time layout shift. Phase D should add minimal code surface, but monitor it. Do **not** re-baseline.
2. **Do not re-baseline**: `tests/fixtures/bench_baseline.json` must stay on the v1.5 Prism baseline during v1.7.
3. **Do not implement dedicated Cart subclasses yet**: NROM/MMC1/MMC3 PoC carts are Phase E/F. Phase D factory must return `nullptr`.
4. **Keep board files working**: Because the factory returns `nullptr`, the `if (cart)` block in the loaders never executes, so board-set `info->Power/Reset/Close` pointers remain active.
5. **Savestate compatibility**: `on_save_pre`/`on_load_post` default to no-ops, so no savestate bytes change.
