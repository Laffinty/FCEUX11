## 5. `DriverCallbacks` 最终签名（Phase A 定稿）

在 build plan §2.1 草图基础上，补入 §3.3 提及但草图漏列的 3 个回调（`get_keyboard_state` / `taseditor_disable_run_function` / `get_thread_name`）。其余字段与 §2.1 一致，此处仅列增补与确认要点：

**确认**（照 §2.1）：40 live 回调 + UI-refresh/dialog 抽象（`set_main_window_text`/`update_ram_search`/`update_cheat_list`/`message_box`）+ `emu_command`。

**Phase A 增补字段**（并入 `struct DriverCallbacks`）：

```cpp
// ---- Input state query (Batch 5 扩展, Phase E, lua-engine.cpp L576/592) ----
void (*get_keyboard_state)(void* out) = nullptr;   // fceux11_lua_GetKeyboardState Qt 路径

// ---- TASEditor (Phase E.4, lua-engine.cpp L469/473 类型统一) ----
void (*taseditor_disable_run_function)() = nullptr; // 取代 core 直接持有 taseditor_lua 符号

// ---- Profiler (Phase E, profiler.cpp L31/135) ----
const char* (*get_thread_name)() = nullptr;         // QThread::currentThread()->objectName()
```

**不变式**（照 §2.1 设计约束，Phase B 验收）：
- 全字段函数指针（非 `std::function`）；POD、可 `memset` 清零；无 vtable。
- `static_assert(std::is_trivially_copyable_v<DriverCallbacks>)`。
- `g_driver()` `__forceinline` 返回引用；未注册时全 nullptr 静态实例。
