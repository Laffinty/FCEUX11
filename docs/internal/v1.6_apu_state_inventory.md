## 3. 关键兼容性约束

### 3.1 `WaveHi` 数组大小

原声明：
```cpp
// src/sound.h:51
extern int32 WaveHi[];
```

实际定义：`int32 WaveHi[40000];`（`src/sound.cpp:39`）

**问题**：不完整数组类型不能做 reference alias。
**方案**：v1.6 中改为完整声明 `extern int32 (&WaveHi)[40000];`，并同步所有定义/声明点。

### 3.2 `SOUNDTS` 宏

```cpp
// src/sound.h:62
#define SOUNDTS (g_cpu.sound_timestamp_ref() + soundtsoffs)
```

`soundtsoffs` 迁入 `Apu` 后，宏变为：
```cpp
#define SOUNDTS (g_cpu.sound_timestamp_ref() + g_apu.soundtsoffs_)
```

但 `sound.h` 不应 include `apu.h` 以保持 hot header 最小化。推荐方案：保留 `extern uint32& soundtsoffs;` alias，宏不变。

### 3.3 `ApuView` 更新

`src/core_state.h:81` 已定义 `ApuView`，v1.6 Phase B 需要：
1. 将 `ApuView` 方法实现改为指向 `g_apu` 成员
2. 新增 `exp_sound()` 访问器返回 `g_apu.exp_sound_()`

## 4. 迁移批次详细说明

### 4.1 批次 C1：输出缓冲与定时

**迁入字段**：
- `wave_[2048+512]` ← `Wave`
- `wave_final_[2048+512]` ← `WaveFinal`
- `wave_hi_[40000]` ← `WaveHi`
- `soundtsinc_` ← `soundtsinc`
- `soundtsoffs_` ← `soundtsoffs`
- `soundtsi_` ← `soundtsi`
- `nesincsize_` ← `nesincsize`
- `swap_duty_` ← `swapDuty`

**为什么先迁这批**：
- 它们被外部文件直接访问最多
- 与 `filter.cpp` / `wave.cpp` / board 文件交互密切
- 先建立 alias 机制，为 C2 大量内部状态迁移打基础

### 4.2 批次 C2：通道状态

**迁入字段**：所有 PSG / 包络 / 扫频 / DMC / 帧计数器状态。

**为什么后迁**：
- 这些变量只在 `sound.cpp` 内部使用
- 数量多但影响范围小
- C1 的 alias 机制稳定后再动，降低风险

## 5. 不迁入 `Apu` 的项的理由

| 项 | 理由 |
|----|------|
| `wlookup1/2` | 纯计算用只读表，无状态 |
| 各种 `Table`/`lengthtable` | 常量/只读 |
| `Do*` 函数指针 | 内部实现细节，v1.6 不改变声音合成算法 |
| `ChannelBC` | 内部临时计数器，生命周期仅限 `FlushEmulateSound` |
| movie sync hack | 属于 movie 子系统，v1.9 Chronicle 处理 |

## 8. 推荐 alias 声明（sound.h Phase B/C）

```cpp
// src/sound.h 兼容层
#include "apu.h"   // Phase B 引入

namespace fceu11 { extern Apu g_apu; }

// C1 alias
extern int32 (&Wave)[2048 + 512];
extern int32 (&WaveFinal)[2048 + 512];
extern int32 (&WaveHi)[40000];
extern uint32& soundtsoffs;
extern uint32& soundtsinc;
extern int32& nesincsize;
extern bool& swapDuty;

// C2 alias
extern uint8 (&PSG)[0x10];
extern uint8& EnabledChannels;
extern uint8& IRQFrameMode;
extern uint16& nreg;
extern uint8& TriCount;
// ... 其余依此类推
```

**实现**：在 `src/sound.cpp` 顶部定义：
```cpp
int32 (&Wave)[2048 + 512] = g_apu.wave_;
int32 (&WaveFinal)[2048 + 512] = g_apu.wave_final_;
int32 (&WaveHi)[40000] = g_apu.wave_hi_;
// ...
```

## 9. 风险项

| 风险 | 说明 |
|------|------|
| `WaveHi` 完整数组声明冲突 | 需在 `sound.h` / `sound.cpp` / `debug.h` 等所有声明点同步 |
| `SOUNDTS` 宏依赖 | 必须保留 `soundtsoffs` alias，否则 `x6502.cpp` 需 include `apu.h` |
| Lua 绑定 | `lua-engine.cpp` 直接读 `PSG`/`RawDALatch`，alias 必须可写/可读 |
| `ApuView` 与 `fceu11::State` | `core_state.cpp` 的 `ApuView` 实现需同步更新 |
