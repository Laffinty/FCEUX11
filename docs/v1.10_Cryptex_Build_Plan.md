### 0.3 现有 FFI（37 个函数已声明）

Rust 端已通过 `fceux11_rust.h` 导出 37 个 FFI 函数，覆盖：
- iNES: header cleanup, mapper name, input lookup, bad ROM check
- FDS: header validate, IRQ tick, block FSM, register helpers
- NSF: header validate, bank compute, NSFROM patch, chip name
- UNIF: board lookup, board flags
- VS Uni: lookup, DIP, coin, service, draw

**关键差距**: C++ 端的完整加载流程（`iNESLoad`/`UNIFLoad`/`NSFLoad`/`FDSLoad`）仍在 C++ 中，尚未迁移。

## Phase A: iNES 解析器全量迁移 (3 commits)

### A.1 iNES 头部解析迁移

**目标**: 将 `src/ines.cpp` 中的头部解析逻辑迁移至 `fceux11-formats::ines`。

**迁移内容**（`ines.cpp` 行 60-200 区域）：
- iNES 1.0 / NES 2.0 头部字段提取
- Trainer 区域检测与内存分配
- ROM/CHR bank 大小计算（处理 NES 2.0 扩展位）
- Mirror mode 推断
- Battery/Trainer 标志解析
- Mapper number 提取（含 NES 2.0 高 4 位 + submapper）

**Rust 新增 FFI**:
```rust
// 完整头部解析（输入: 16 字节原始头部，输出: 结构化结果）
pub fn fceux11_rust_ines_parse_header(
    header_bytes: *const u8,
    out: *mut FceuInesParseResult,
) -> bool;

// ROM/CHR 布局计算
pub fn fceux11_rust_ines_compute_layout(
    header: *const FceuInesParseResult,
    out: *mut FceuInesLayout,
) -> bool;
```

**文件**:
- `src/rust/crates/fceux11-formats/src/ines.rs` — 扩展
- `src/rust/crates/fceux11-formats/src/ines/ines_data.rs` — 可能需要新增 NES 2.0 数据表
- `src/ines.cpp` — 替换头部解析为 Rust FFI 调用

### A.2 iNES ROM 加载迁移

**目标**: 将 `iNESLoad` / `iNESCartLoad` 的核心逻辑迁移至 Rust。

**迁移内容**（`ines.cpp` 行 200-600 区域）：
- ROM/CHR 数据读取与内存分配
- Trainer 数据加载
- PRG/CHR bank 映射设置（`SetupCartPRGMapping` / `SetupCartCHRMapping`）
- Mapper 初始化（`Mapper{N}_Init` 调用）
- MD5/CRC32 计算
- `CartInfo` 结构体填充

**Rust 新增**:
```rust
// 完整 iNES 加载（输入: 文件数据，输出: CartInfo 结构）
pub fn fceux11_rust_ines_load(
    file_data: *const u8,
    file_len: usize,
    out_cart: *mut FceuInesCartResult,
) -> bool;

// ROM/CHR 内存布局结果
#[repr(C)]
pub struct FceuInesCartResult {
    pub prg_data: *const u8,
    pub prg_size: u32,
    pub chr_data: *const u8,
    pub chr_size: u32,
    pub trainer_data: *const u8,
    pub trainer_size: u32,
    pub mapper_no: u32,
    pub submapper: u8,
    pub mirror: u32,
    pub battery: u32,
    pub md5: [u8; 16],
    pub crc32: u32,
}
```

**文件**:
- `src/rust/crates/fceux11-formats/src/ines.rs` — 扩展
- `src/ines.cpp` — `iNESLoad` 改为调用 Rust FFI

### A.3 iNES 桥接层收尾

**目标**: `src/ines.cpp` 缩减至 < 100 行 FFI 桥接代码。

**保留内容**（C++ 端）：
- `FCEU_LoadGame` 中的格式分发逻辑（iNES vs UNIF vs NSF vs FDS）
- `iNESGI_Close` / `iNESGI_SetInput` 生命周期钩子
- `AddExState` 注册（savestate 兼容）

**移除/归档**：
- 原 `iNESLoad` 中的头部解析代码 → Rust
- 原 `iNESCartLoad` 中的 ROM/CHR 分配代码 → Rust
- mapper 名称查找表 → Rust（已完成）
- bad ROM 检测 → Rust（已完成）

**验收**:
- `src/ines.cpp` < 100 行
- 5 个 golden savestate ROM 加载测试通过
- mapper_byte_diff_test 通过

## 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| iNES 加载逻辑复杂，迁移引入回归 | ROM 加载失败 | 逐函数迁移 + golden savestate 测试 |
| FDS 磁盘 I/O 涉及硬件状态机 | FDS 游戏崩溃 | 复用已有 `fds.rs` IRQ/block FSM |
| UNIF board 查找表不完整 | 冷门 mapper 加载失败 | 对比 C++ `bmap[]` 表逐项验证 |
| NSF NSFROM patch 二进制兼容 | NSF 播放异常 | 字节级对比测试 |
| 性能退步 | 加载变慢 | benchmark 监控 |
