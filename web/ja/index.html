概要

はじめに

FCEUX11 は、FCEUX の NES/Famicom エミュレーターから派生したプロジェクトで、Windows 向けに最適化されています。

FCEUX の卓越したエミュレーション精度を継承しながら、Qt 6 ベースの UI によってモダンな Windows ネイティブ体験を提供します。12 言語の多言語対応と、デバッグ・TAS ツール群を開発者や TAS 愛好家の双方に向けて搭載しています。

現在も内部リファクタリングとパフォーマンス最適化を継続しており、高負荷な状況でも効率的・滑らか・安定動作を実現。往年の名作をもう一度楽しみたい方も、ROM ハックに踏み込みたい方も、FCEUX11 が NES ゲームをスムーズに美しく動かします。

新機能

v1.16

2026-08-06 リリース · v1.15 → v1.16 の振り返り
01

複数のゲームの互換性問題を修正

前バージョンでは、画面表示・音声・入力応答にわずかな不具合が残るゲームが少数ありました。本バージョンでは、VBL タイミング調整、APU クロックジッタ、PPU データバッファ読み取り、PPU データラッチ減衰など、いくつかのコアタイミング機構を修正しました。

具体的な数字：blargg 公的テスト ROM スイート（177 本）の合格率は、前バージョンの 76.3% から 81.4% に向上しました。

02

Lua スクリプトインターフェースを FCEUX と完全一致

TAS 作者が使う主要な Lua インターフェース（joypad、memory など）の挙動が、FCEUX11 と FCEUX で完全一致するようになりました。元々 FCEUX 向けに書かれたスクリプトを、FCEUX11 でもそのまま変更なしで使えます。

追加されたインターフェース：joypad.get/set、memory.readwrite、memory.readwordsigned、memory.getregister、memory.registerexec。

03

Lua bit.* ビット演算が LuaBitOp 標準に準拠

ビット演算ライブラリ（bit.rshift、bit.tohex など）のセマンティクスが LuaBitOp 1.0.2 標準に準拠しました：右シフトは論理シフト（上位ビットを 0 で埋める）、tohex は負数に大文字で出力、などです。元々 FCEUX 上で書かれビット演算に依存するスクリプトは、FCEUX11 に移植しても実装差による意図しない結果になりません。

04

長時間の録画とセーブステートがより安定

PPU のタイミングとアドレス解決に関するいくつかの問題を修正しました（ppu_read_buffer 3 箇所、ppu_open_bus データラッチ減衰）。長時間の TAS 録画中、特定フレームで同期がずれることが少なくなります。セーブステートの互換性についても回帰テストによる網羅的な検証体制が整いました。
