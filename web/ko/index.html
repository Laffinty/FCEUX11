소개

개요

FCEUX11 은 FCEUX NES/Famicom 에뮬레이터에서 파생된 프로젝트로, Windows 용으로 깊이 최적화되었습니다.

FCEUX 의 뛰어난 에뮬레이션 정확도를 계승하면서 Qt 6 GUI 로 현대적인 Windows 네이티브 경험을 새롭게 다듬으며, 12 개 언어 다국어 지원과 함께 개발자와 스피드러너를 위한 디버깅·TAS 도구 세트를 기본 탑재합니다.

내부 코어 리팩터링과 성능 최적화를 지속적으로 추진하여, 높은 부하 상황에서도 효율적이고 부드러우며 안정적인 동작을 유지합니다.

실험적 Game Boy Advance (GBA) 에뮬레이션이 추가되었으며, 기존 UI·저장 시스템·단축키·디버깅 인프라를 그대로 활용합니다. GBA 기능은 Beta 단계로 화면에 워터마크가 있으며, 일부 하드웨어 기능은 아직 완전히 구현되지 않았습니다.

01

크래시 보고 방식 개선

기존 로직에서는 크래시 한 번에 요약 줄이 두 개 생기고 기존 최소 덤프를 덮어썼으며, 포착되지 않은 C++ 예외에서는 콜 스택이 출력되지 않았습니다. 크래시 수집 모듈은 이제 수정되었습니다. 크래시 이벤트마다 덤프 파일 한 개와 요약 줄 한 개만 생성하며 과거 덤프를 덮어쓰지 않습니다. C++ 예외를 포함한 모든 크래시에 심볼화된 콜 스택이 함께 남습니다. 크래시 현장 정보가 더 이상 빠짐없이 온전히 보존되며, 관련 데이터는 로컬에만 보관되고 자동으로 업로드되지 않습니다.

02

잠금 테스트 절차 변경

에뮬레이터 Rust 코어에는 약 1197개의 자동화 잠금 테스트가 있습니다. 이전에는 이 테스트들이 유지자의 로컬에서만 실행되어 잠금 관련 문제가 릴리스 때까지 발견되지 않을 수 있었습니다. 이제 매 CI 실행마다 전부 수행되며, 프로젝트는 한 커밋에 대해 전체 빌드를 두 번 수행하지 않습니다. 정식 릴리스 전에 전체 잠금 테스트 검증이 완료되므로 유지자의 로컬 환경 검증에 의존하지 않습니다.
