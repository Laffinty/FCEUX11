소개

개요

FCEUX11 은 FCEUX NES/Famicom 에뮬레이터에서 파생된 프로젝트로, Windows 용으로 깊이 최적화되었습니다.

FCEUX 의 뛰어난 에뮬레이션 정확도를 계승하면서 Qt 6 GUI 로 현대적인 Windows 네이티브 경험을 새롭게 다듬으며, 12 개 언어 다국어 지원과 함께 개발자와 스피드러너를 위한 디버깅·TAS 도구 세트를 기본 탑재합니다.

내부 코어 리팩터링과 성능 최적화를 지속적으로 추진하여, 높은 부하 상황에서도 효율적이고 부드러우며 안정적인 동작을 유지합니다.

실험적 Game Boy Advance (GBA) 에뮬레이션이 추가되었으며, 기존 UI·저장 시스템·단축키·디버깅 인프라를 그대로 활용합니다. GBA 기능은 Beta 단계로 화면에 워터마크가 있으며, 일부 하드웨어 기능은 아직 완전히 구현되지 않았습니다.

2026-11-15 배포 · 메모리 안전성, 세이브·녹화 안정성, Lua API 수정
01

여러 메모리 오버런을 수정해, 깨진 카트리지·저장 파일로도 꺼지지 않습니다

mapper 218의 CHR-RAM 매핑이 페이지 번호를 바이트 오프셋으로 사용해, 마스킹되지 않은 PPU 주소가 네임테이블 영역 밖으로 기록될 수 있었습니다. CHR-RAM이 8K 미만인 카트리지에서는 $2007 쓰기가 힙을 최대 7KB 넘을 수 있었고, 두 곳 모두 업스트림 구현과 동일하게 고쳤습니다. 이런 카트리지의 화면과 기존 무비 재생은 이에 맞춰 달라집니다. 비 ASCII 바이트가 섞인 깨진 무비는 이전에 프로세스를 중단시켰지만, 이제는 GUID 전체를 0으로 기록합니다.

02

프로세스 간 세이브, AVI 녹화, 패드 상태의 크로스 스레드 경쟁 수정

VRC7 사운드 구조의 포인터가 세이브 파일에 그대로 저장되어, 다른 프로세스에서 읽으면 매달린 포인터가 되어 충돌했습니다. 이제는 읽을 때 파생 데이터를 재구성하면서 음색 위상은 그대로 유지합니다. AVI 링 버퍼, TraceLogger, CDL 카운터의 인덱스를 원자 변수로 바꿔 끝 프레임 손실과 데이터 경쟁을 없앴고, 비 FDS 카트리지의 .cdl 출력도 업스트림과 일치시켰습니다.

03

Lua 스크립트가 읽던 키 이름이 통째로 어긋나 있었습니다, 마우스도 함께 수정

input.get()의 키 이름 표가 Windows 가상 키 코드로 SDL 스캔코드 배열을 참조해, 키보드 이름 96개가 모두 틀렸고(capslock이 Q로 보고) 토글 키 3개는 항상 false였습니다. 이제 스캔코드 기준으로 바꿨습니다. 마우스 click은 비트 마스크에 중버튼 지원을 더해, 두 키를 동시에 눌러도 둘 다 읽히지 않던 문제도 해결했습니다.

04

Famicom 마이크를 레벨 직접 읽기로 바꾸고 실기 동작에 맞췄습니다

$4016의 bit 2는 1996년의 순차 반전 해킹으로, 누르는 동안 1과 0이 번갈아 읽히고 두 컨트롤러 포트 모두에 영향을 줬습니다. NESdev와 Mesen2를 함께 참고해 레벨 직접 읽기로 바꿨으며, 누르면 항상 1, 놓으면 0이고 P2 포트에만 적용됩니다.

05

GBA 측 치명적 크래시 지점 2곳을 제거하고, 재현 가능한 테스트와 진단 프로브를 보강

스프라이트 속성의 잘못된 값 2개가 렌더링 도중 크래시를 일으켜 릴리스 빌드에서는 곧바로 종료됐습니다. 이제 실기와 같이 스프라이트 표시 안 함으로 처리합니다. 함께 최소 재현 픽스처 9개와 상시 가드 3개를 추가했고, 진단 프로브는 BIOS 시스템 콜 기록·크래시 포착·입력 주입을 지원해 남은 호환성 문제를 더 쉽게 좁힐 수 있게 되었습니다.
