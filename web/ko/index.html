개요

FCEUX11 은 FCEUX NES/Famicom 에뮬레이터에서 파생된 프로젝트로, Windows 용으로 최적화되었습니다.

FCEUX 의 뛰어난 에뮬레이션 정확도를 계승하면서 Qt 6 기반의 UI 로 현대적인 Windows 네이티브 경험을 제공하며, 개발자와 스피드러너를 위한 12 개 언어 다국어 지원과 디버깅·TAS 도구 세트를 기본 탑재합니다.

내부 리팩터링과 성능 최적화를 지속적으로 진행하여, 높은 부하 상황에서도 효율적이고 부드러우며 안정적인 동작을 유지합니다. 어린 시절의 명작을 다시 즐기고 싶거나, ROM 해킹에 깊이 들어가고 싶을 때, FCEUX11 은 NES 게임을 가장 매끄럽게 실행합니다.

2026-07-16 배포 · v1.0 ~ v1.15 회고
01

12 개 언어, 즉시 사용 가능

UI 는 12 개 언어 — 简体中文·繁體中文·English·日本語·한국어·Español·Français·Deutsch·Tiếng Việt·ไทย·हिन्दी·العربية (완전한 RTL 레이아웃 포함) 를 지원합니다. 최초 실행 시 Windows 표시 언어를 자동으로 감지하여 별도 설정이 필요 없습니다.

02

충돌 없는 플레이

수동 메모리 관리(malloc/free) 를 완전히 폐기하고 자동 메모리 관리로 전환했습니다. 힙 double-free 등 핵심 충돌 버그를 수정하여 장시간 플레이에서도 안정적으로 동작합니다.

03

더 빠르게, 더 매끄럽게

LTO/PGO 컴파일 최적화와 링커 축소(/OPT:REF, /OPT:ICF) 로 콜드 스타트와 게임 로딩이 체감될 만큼 빨라졌습니다. 프레임 페이싱이 안정되어 오래된 PC 에서도 끊김과 음 끊김 없이 부드럽게 동작합니다.

04

PPU 렌더링 개편 : 프레임 타임 52% 감소

21 건의 알고리즘·마이크로 구조 최적화로 PPU 렌더링 파이프라인을 재구성: 스프라이트 2 단계 LUT 디코드, X-bucket 사전 분류, strict aliasing UB 근본 해결, 루프 모듈로를 wrap-around 로 교체, dispatcher 캐시 재사용. 단일 스레드 PPU 프레임 타임이 hotfix1 의 1.125 ms 에서 0.535 ms (−52.4 %) 로 단축되어 계획 상한 42% 를 초과 달성했습니다. 169 개 mapper 에서 0 바이트 차이로 화질 정확도는 그대로입니다.
