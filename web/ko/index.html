개요

FCEUX11 은 FCEUX NES/Famicom 에뮬레이터에서 파생된 프로젝트로, Windows 용으로 최적화되었습니다.

FCEUX 의 뛰어난 에뮬레이션 정확도를 계승하면서 Qt 6 기반의 UI 로 현대적인 Windows 네이티브 경험을 제공하며, 개발자와 스피드러너를 위한 12 개 언어 다국어 지원과 디버깅·TAS 도구 세트를 기본 탑재합니다.

내부 리팩터링과 성능 최적화를 지속적으로 진행하여, 높은 부하 상황에서도 효율적이고 부드러우며 안정적인 동작을 유지합니다. 어린 시절의 명작을 다시 즐기고 싶거나, ROM 해킹에 깊이 들어가고 싶을 때, FCEUX11 은 NES 게임을 가장 매끄럽게 실행합니다.

01

여러 게임의 호환성 문제 수정

이전 버전에서는 화면·음향·입력 응답에서 사소한 결함을 보이는 게임이 소수 있었습니다. 이번 버전에서는 VBL 타이밍 정렬, APU 클럭 지터, PPU 데이터 버퍼 읽기, PPU 데이터 래치 감쇠 등 핵심 타이밍 메커니즘을 수정했습니다.

구체적인 수치: blargg 공식 테스트 ROM 스위트(177개)의 통과율이 이전 버전의 76.3%에서 81.4%로 향상되었습니다.

02

Lua 스크립트 인터페이스가 FCEUX와 완전히 일치

TAS 작가가 자주 사용하는 Lua 인터페이스(joypad, memory 등)의 동작이 FCEUX11과 FCEUX에서 완전히 동일해졌습니다. 기존에 FCEUX용으로 작성된 스크립트를 수정 없이 바로 FCEUX11에서 사용할 수 있습니다.

추가된 인터페이스: joypad.get/set, memory.readwrite, memory.readwordsigned, memory.getregister, memory.registerexec.

03

Lua bit.* 비트 연산이 LuaBitOp 표준을 따름

비트 연산 라이브러리(bit.rshift, bit.tohex 등)의 의미가 LuaBitOp 1.0.2 표준과 정렬되었습니다. 우측 시프트는 논리 시프트(상위 비트를 0으로 채움), tohex는 음수에 대해 대문자로 출력하는 등입니다. FCEUX에서 작성되어 비트 연산에 의존하는 스크립트는 FCEUX11로 이식해도 구현 차이로 인한 예기치 못한 결과가 발생하지 않습니다.

04

장기 녹화와 세이브 스테이트의 안정성 향상

PPU 타이밍과 주소 지정 경로의 여러 문제를 수정했습니다(ppu_read_buffer 세 곳 수정, ppu_open_bus 데이터 래치 감쇠). 장기 TAS 녹화 중 특정 프레임에서 동기화가 어긫나는 일이 줄어들었습니다. 세이브 스테이트 호환성 또한 회귀 테스트로 완전히 검증됩니다.
