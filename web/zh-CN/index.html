简介

FCEUX11 是基于 FCEUX 的 NES/Famicom 模拟器衍生项目，针对 Windows 平台深度优化。

在继承 FCEUX 卓越模拟精度的同时，采用 Qt 6 图形界面重塑了现代 Windows 原生体验，并提供 12 种语言的多语言支持，以及面向开发者和速通玩家的调试与 TAS 工具集。

项目持续推进内部核心重构与性能优化工作，致力于让模拟器在高负载场景下依旧保持高效、流畅与稳定。

新增实验性 Game Boy Advance（GBA）模拟支持，复用现有 UI、存档系统、热键与调试基础设施；GBA 功能处于 Beta 阶段，自带画面水印，部分硬件特性尚未完整实现。

01

GBA 卡带兼容性大幅改善，多张商用卡片已可正常运行

此前多张商用手写卡带在模拟器上表现为进入游戏后卡死、画面无法加载或直接闪退退出。本版定位并修复了三类根因：未实现的 BIOS 系统调用会使 CPU 在 BIOS 例程中永久自旋；精灵属性中的两个非法取值会触发渲染线程崩溃，发布版因此直接闪退；存档芯片容量模型不完整，EEPROM 卡片的存档文件尺寸长期错误。三处分别改为调用后正常返回并记录调用号、按真机语义将精灵视为不显示、以及按芯片实际容量读写。《宝可梦 火红》经实测已确认兼容，此前完全无法加载任何画面；另有三张卡片的机器判据已不再复现卡死与黑屏，画面观感仍待人工最终确认。GBA 整体仍处于 Alpha 阶段，本版目标是解决无法运行的问题，不代表画面与音效已完全对齐真机。

02

FC 侧修复卡片装载与映射问题，消除无法加载与灰屏

iNES 装载器此前会直接拒绝主 ROM 容量非 2 的幂的卡片（相当一部分自制卡与改版卡属于此类，用户侧仅显示为未知 ROM 文件格式），现已改为按文件实际字节切分、仅在建立内存映射时补齐；mapper 191、199、198 虽已有实现却未注册进映射表，必然导致灰屏，现已补齐注册，并让 199 与 198 各跑自己的初始化例程（二者的扩展寄存器与工作内存布局不同于通用例程）；ROM 修正表的查表键与写回逻辑存在偏差，致使 251 条修正长期整体失效，现已与上游 FCEUX 2.6.6 / 2.7.0 逐位一致。实测 9 张 NES 卡片中有 8 张与上游行为一致，《吞食天地2》现已运行出与上游一致的画面，此前为全屏灰屏。

03

补齐 BIOS 系统调用，并将测试门禁升级为可复现、可证伪

商业卡加载差分压缩数据所依赖的三项差分反滤波调用（系统调用号 16 / 17 / 18）此前完全未实现，卡片读到的数据因此错误；现已按 GBATEK 权威格式逐条实现，并同时补齐声音偏置、MIDI 音高换算、合卡与定制停机四项调用，以及寄存器复位调用按 GBATEK 明文规定的强制空白写入，另修复了 mode 5 位图的页面翻转，此前始终只显示第 0 页。测试门禁同步升级：GBA 侧新建 14 条最小可复现夹具与 3 条常驻守卫，红色复现器已清零；F11QA 矩阵共 122 条用例，CI 仅将不允许回归作为红线；每条新增断言均执行变异验证，即有意破坏实现以确认对应断言确实失败，本轮据此发现并修正了断言取值过小、两种实现均可通过的一类无效门禁。
