簡介

FCEUX11 是基於 FCEUX 的 NES/Famicom 模擬器衍生專案，針對 Windows 平台深度最佳化。

在繼承 FCEUX 卓越模擬精度的同時，採用 Qt 6 圖形介面重塑現代 Windows 原生體驗，並提供 12 種語言的多語言支援，以及面向開發者與速通玩家的除錯與 TAS 工具集。

專案持續推進內部核心重構與效能最佳化工作，致力於讓模擬器在高負載場景下依舊保持高效、流暢與穩定。

新增實驗性 Game Boy Advance（GBA）模擬支援，沿用現有 UI、存檔系統、快捷鍵與除錯基礎設施；GBA 功能處於 Beta 階段，畫面自帶浮水印，部分硬體特性尚未完整實作。

實驗性新增 Game Boy Advance（GBA）模擬支援

新增實驗性 Game Boy Advance（GBA）模擬功能，現已支援 .gba 卡帶，並與 NES 側完全解耦。同時修正輸入設定重開後按鍵全空、GBA 實體卡帶無法啟動、部分顯示驅動程式下 GBA 黑屏、GBA 畫面紅藍通道互換，以及核心 VBlankIntrWait 自鎖。

02

修復《Mario Kart: Super Circuit》啟動白畫面問題

《Mario Kart: Super Circuit》此前啟動後顯示白畫面並停止回應：中斷喚醒休眠中的處理器時，返回位址未計入一條指令的寬度，喚醒後同一系統呼叫被執行兩次；修復後經 1200 幀逐幀校驗，畫面持續更新並正常進入標題畫面。同一輪修復亦處理了 ARM 模式程式的 BIOS 呼叫缺陷：模擬器此前從錯誤的位段讀取呼叫編號，每次呼叫均被判定為系統重設，程式在啟動後立即進入重設迴圈。上述缺陷均曾在內部測試全部通過的情況下長期存在，最終經真實卡帶測試發現，相關排查手段已據此加強。

03

指令時序與計時器修正

經與官方硬體測試逐項核對確認：處理器每條指令的取指與執行兩個階段此前被重複計時，指令耗時被計為實際值的兩倍，現已依照真實機器行為計價。計時器方面修正三處缺陷：分頻倍率此前讀取了錯誤暫存器，始終以 1 倍頻率工作；計時器之間的級聯此前不生效；真實機器在啟動瞬間存在的固定延遲亦已補入。硬體測試卡的計時器三項現已全部通過。

04

預取與 DMA 計時修正（硬體基準 24/33 → 30/33）

繼續對齊真實機器的兩項機制。取指預取緩衝：此前任何資料存取均會中斷預取命中判定，現已改為僅依據取指流判定，預取緩衝兩項讀數與官方期望值完全一致。DMA（批次資料傳輸）工作期間，計時器此前會完全停止，現已依照真實機器行為隨傳輸逐單元繼續計時，並計入傳輸開始時的固定延遲。五項記憶體計時測試全部通過，硬體基準總成績由 24/33 提升至 30/33；其餘兩項（DMA 顯示觸發與通道優先權）已列入後續計畫。
