簡介

FCEUX11 是基於 FCEUX 的 NES/Famicom 模擬器衍生專案，針對 Windows 平台深度最佳化。

在繼承 FCEUX 卓越模擬精度的同時，採用 Qt 6 圖形介面重塑現代 Windows 原生體驗，並提供 12 種語言的多語言支援，以及面向開發者與速通玩家的除錯與 TAS 工具集。

專案持續推進內部核心重構與效能最佳化工作，致力於讓模擬器在高負載場景下依舊保持高效、流暢與穩定。

新增實驗性 Game Boy Advance（GBA）模擬支援，沿用現有 UI、存檔系統、快捷鍵與除錯基礎設施；GBA 功能處於 Beta 階段，畫面自帶浮水印，部分硬體特性尚未完整實作。

2026-11-08 發布 · 效能、精度與除錯工具全面強化
01

模擬器執行速度大幅提升，遊玩更流暢

這次重點優化 NES 與 GBA 兩大模擬器的效能。NES 端修正除錯模組的無效運算，並最佳化音訊與畫面算繪邏輯，整體 CPU 負載下降 27%；高畫質音訊模式效能直接提升近一半，就算開啟高品質音效，模擬器也不會卡頓。GBA 方面解決了影格畫面產生、存檔時重複編碼的資源浪費問題，畫面產生速度大幅提升，存檔耗時減半。最佳化不改動遊戲存檔格式，也不改動遊戲畫面與音訊內容，原本遊戲的表現完全不變，只是降低了電腦的 CPU 使用量，低配電腦也能更順暢地跑遊戲。

02

修正一批硬體模擬 BUG，遊戲行為更接近真機

修正了 OAM DMA 硬體模擬缺陷，解決部分遊戲畫面異常；修正 SNES 滑鼠的輸入協定問題，滑鼠輸入邏輯回歸正確。同時修正多例測試案例的「假報錯」——不是模擬器有錯，而是測試執行的影格數給得不夠，調整影格上限後，測試結果更加真實可信。開啟中斷專項改造，改善 CPU 中斷處理邏輯，讓中斷回應時序更貼近真實的 6502 硬體，解決部分對時序敏感遊戲的執行偏差。

03

強化除錯工具與自動化測試

擴充命令列下的除錯日誌、效能統計、硬體行為探針等工具，修復反組譯顯示錯誤，完善腳本介面，方便開發者排查遊戲 BUG。
