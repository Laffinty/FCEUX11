簡介

FCEUX11 是基於 FCEUX 的 NES/Famicom 模擬器衍生專案，針對 Windows 平台深度最佳化。

在繼承 FCEUX 卓越模擬精度的同時，採用 Qt 6 圖形介面重塑現代 Windows 原生體驗，並提供 12 種語言的多語言支援，以及面向開發者與速通玩家的除錯與 TAS 工具集。

專案持續推進內部核心重構與效能最佳化工作，致力於讓模擬器在高負載場景下依舊保持高效、流暢與穩定。

新增實驗性 Game Boy Advance（GBA）模擬支援，沿用現有 UI、存檔系統、快捷鍵與除錯基礎設施；GBA 功能處於 Beta 階段，畫面自帶浮水印，部分硬體特性尚未完整實作。

01

GBA 卡帶相容性大幅改善，多張商用卡帶已可正常執行

此前多張商用同人卡帶在模擬器上表現為進入遊戲後卡死、畫面無法載入或直接閃退退出。本版定位並修復了三類根因：未實作的 BIOS 系統呼叫會使 CPU 在 BIOS 例程中永久自旋；精靈屬性中的兩個非法取值會觸發算繪執行緒崩潰，出版版因此直接閃退；儲存晶片容量模型不完整，EEPROM 卡帶的存檔檔案尺寸長期錯誤。三處分別改為呼叫後正常返回並記錄呼叫號碼、按真機語義將精靈視為不顯示、以及依晶片實際容量讀寫。《寶可夢 火紅》經實測已確認相容，此前完全無法載入任何畫面；另有三張卡帶的機器判據已不再重現卡死與黑畫面，畫面觀感仍待人工最終確認。GBA 整體仍處於 Alpha 階段，本版目標是解決無法執行的問題，不代表畫面與音效已完全對齊真機。

02

FC 側修正卡帶裝載與映射問題，消除無法載入與灰畫面

iNES 裝載器此前會直接拒絕主 ROM 容量非 2 的冪的卡帶（相當一部分自製卡與改版卡屬於此類，使用者側僅顯示為未知 ROM 檔案格式），現已改為依檔案實際位元組切分、僅在建立記憶體映射時補齊；mapper 191、199、198 雖已有實作卻未註冊進映射表，必然導致灰畫面，現已補齊註冊，並讓 199 與 198 各跑自己的初始化流程（二者的擴充暫存器與工作記憶體配置不同於通用流程）；ROM 修正表的查表鍵與寫回邏輯存在偏差，致使 251 條修正長期整體失效，現已與上游 FCEUX 2.6.6 / 2.7.0 逐位元一致。實測 9 張 NES 卡帶中有 8 張與上游行為一致，《吞食天地2》現已執行出與上游一致的畫面，此前為全螢幕灰畫面。

03

補齊 BIOS 系統呼叫，並將測試門檻升級為可重現、可驗證

商用卡帶載入差分壓縮資料所依賴的三項差分反濾波呼叫（系統呼叫號 16 / 17 / 18）此前完全未實作，卡帶讀到的資料因此錯誤；現已依 GBATEK 權威格式逐條實作，並同時補齊聲音偏置、MIDI 音高換算、合卡與自訂停機四項呼叫，以及暫存器重設呼叫依 GBATEK 明文規定的強制空白寫入，另修復了 mode 5 點陣圖的頁面翻轉，此前始終只顯示第 0 頁。測試門檻同步升級：GBA 側新建 14 條最小可重現測試案例與 3 條常駐守衛，紅色復現項已清零；F11QA 矩陣共 122 條案例，CI 僅將不允許回歸作為紅線；每條新增斷言皆執行變異驗證，即刻意破壞實作以確認對應斷言確實失敗，本輪據此發現並修正了斷言取值過小、兩種實作皆可通過的一類無效門檻。
