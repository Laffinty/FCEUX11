# v1.10 Cryptex Phase A — iNES 解析器全量迁移 实施计划

## 背景

`src/ines.cpp` (1017 行) 的 `iNESLoad()` 是 ~300 行的混合函数：纯解析逻辑 + 副作用（内存分配、文件 I/O、mapper 初始化）。目标是将纯解析逻辑迁移至 Rust `fceux11-formats::ines`，C++ 端缩减为 FFI 桥接层。

## 迁移边界

### 迁移至 Rust（纯解析，无副作用）

| 功能 | 当前位置 | 行数 |
|------|----------|------|
| Header 魔术校验 | ines.cpp:613 | 2 |
| NES 2.0 字段提取 (wram/vram/submapper) | ines.cpp:620-629 | 10 |
| Mapper 号组装 | ines.cpp:631-633 | 3 |
| Mirroring 位解析 | ines.cpp:635-641 | 7 |
| VS UniSystem 类型检测 | ines.cpp:660-706 | 47 |
| Trainer/Battery 标志 | ines.cpp:709,797 | 2 |
| MD5/CRC32 计算 | ines.cpp:725-739 | 15 |
| 日志格式化 | ines.cpp:741-773 | 33 |
| **合计** | | **~120 行** |

### 保留在 C++（有副作用）

| 功能 | 原因 |
|------|------|
| `FCEU_fread` 文件 I/O | 需要 `FCEUFILE*` 句柄 |
| `FCEU_malloc` 内存分配 | 需要全局 `ROM`/`VROM` 指针 |
| `SetupCartPRGMapping` 等 | 需要 `g_bus` 引用 |
| `iNES_Init` mapper 初始化 | 需要 `bmap[]` 函数指针表 |
| `create_cart_for_mapper` | 需要 C++ 对象工厂 |
| `CheckHInfo` 应用修正 | 修改全局 `MapperNo`/`Mirroring`/`VROM_size` |
| VS UniSystem PPU/Type 设置 | 写入 `GameInfo` 全局 |

## Phase A.1：Rust 头部解析 FFI（1 commit）

### 新增 Rust 函数

**文件**: `src/rust/crates/fceux11-formats/src/ines.rs`

```rust
/// iNES 头部完整解析结果
#[repr(C)]
pub struct FceuInesParseResult {
    pub is_nes2: bool,
    pub mapper_no: u32,
    pub submapper: u8,
    pub mirroring: i32,          // 0=H, 1=V, 2=four-screen
    pub mirroring_as_2bits: i32,
    pub battery: bool,
    pub trainer: bool,
    pub rom_size_16kb: u32,      // PRG-ROM in 16KB units
    pub vrom_size_8kb: u32,      // CHR-ROM in 8KB units
    pub rom_size_raw: u32,       // 原始 PRG-ROM（不四舍五入）
    pub wram_size: u32,          // NES 2.0 WRAM 字节
    pub battery_wram_size: u32,  // NES 2.0 battery WRAM 字节
    pub vram_size: u32,          // NES 2.0 VRAM 字节
    pub battery_vram_size: u32,  // NES 2.0 battery VRAM 字节
    pub vs_system: i32,          // 0=cart, 1=VS UniSystem, -1=unsupported
    pub vs_ppu: i32,             // VS PPU 类型
    pub vs_type: i32,            // VS 系统类型
    pub tv_system: i32,          // 0=NTSC, 1=PAL
}

/// 完整解析 iNES 16 字节头部
/// 返回 true 表示有效 iNES，false 表示无效
#[unsafe(no_mangle)]
pub unsafe extern "C" fn fceux11_rust_ines_parse_header(
    header_bytes: *const u8,
    out: *mut FceuInesParseResult,
) -> bool
```

**实现逻辑**（从 ines.cpp:613-706 迁移）：
1. 校验 "NES\x1A" magic
2. 调用已有的 `header_cleanup()`
3. 检测 NES 2.0 (`rom_type2 & 0x0C == 0x08`)
4. 提取 NES 2.0 字段（wram_size 等，使用 `64 << n` 公式）
5. 组装 mapper 号（低 4 + 高 4 + NES2 扩展）
6. 解析 mirroring（bit3=四屏, bit0=垂直/水平）
7. 调用已有的 `fceux11_rust_cart_compute_rom_sizes()`
8. 检测 VS UniSystem 类型和 PPU
9. 提取 battery/trainer 标志

### C++ 端改造

**文件**: `src/ines.cpp` 的 `iNESLoad()` 函数

改造后的流程：
```
iNESLoad(name, fp, OverwriteVidMode)
├─ fread 16 字节 → head
├─ fceux11_rust_ines_parse_header(&head, &parseResult)  ← 新
│   ├─ 返回 false → return LOADER_INVALID_FORMAT
│   └─ 返回 true → 从 parseResult 填充全局变量
│       MapperNo = parseResult.mapper_no
│       Mirroring = parseResult.mirroring
│       ROM_size = parseResult.rom_size_16kb
│       VROM_size = parseResult.vrom_size_8kb
│       iNESCart.ines2/submapper/wram_size/... = parseResult.*
│       GameInfo->type = parseResult.vs_system
│       GameInfo->vs_ppu/vs_type = parseResult.vs_*
├─ FCEU_malloc(ROM_size << 14)  ← 保留在 C++
├─ FCEU_fread(ROM/VROM)         ← 保留在 C++
├─ fceux11_rust_ines_compute_hash(ROM, ..., VROM, ..., &hash)  ← 新
│   iNESCart.MD5 = hash.md5
│   iNESGameCRC32 = hash.crc32
│   partialmd5 = hash.partial_md5
├─ 日志输出（使用 parseResult 字段）  ← 简化
├─ SetInput / CheckHInfo / CheckBad / VSUniCheck  ← 保留
├─ SetupCartCHRMapping / SetupCartMirroring  ← 保留
├─ iNES_Init(MapperNo)  ← 保留
├─ Cart 对象创建  ← 保留
└─ return LOADER_OK
```

### 预期效果

- `iNESLoad()` 从 ~300 行缩减至 ~150 行
- 纯解析逻辑（~120 行）迁移至 Rust
- Rust 新增 ~100 行代码（parse_header + compute_hash）

## Phase A.2：Rust ROM 加载辅助（1 commit）

### 新增 Rust 函数：ROM 校正应用

当前 `CheckHInfo()` 有两部分：
1. Rust `fceux11_rust_ines_check_hinfo()` — 已迁移（ROM_CORRECTIONS 查找）
2. C++ 应用修正逻辑 — 修改全局变量 + 硬编码 mapper 修正

将 C++ 应用逻辑封装为 Rust 函数：

```rust
/// 应用 ROM 校正到解析结果
/// 输入: parse_result + hinfo_result + mapper 118/24/26/99 特殊修正
/// 输出: 修正后的 parse_result（修改 mapper_no/mirroring/battery）
#[unsafe(no_mangle)]
pub unsafe extern "C" fn fceux11_rust_ines_apply_corrections(
    parse: *mut FceuInesParseResult,
    hinfo: *const FceuInesHInfoResult,
    partial_md5: u64,
    has_chr_rom: bool,
) -> i32  // 返回 tofix 位掩码
```

**迁移内容**（ines.cpp:206-294）：
- `sMasterRomInfo` 查找 → 迁移至 `ines_data.rs`
- mapper 118/24/26 四屏修正 → Rust
- mapper 99 四屏隐式设置 → Rust
- `clear_vrom` / `force_battery` / `mirror` / `mapper` 修正 → Rust
- `tofix` 位掩码返回给 C++ 用于日志

## Phase A.3：桥接层收尾（1 commit）

### 目标

`src/ines.cpp` 从 1017 行缩减至 < 500 行（而非计划的 < 100 行）。

**原因**：`iNES_Init()` (~50 行)、`iNESGI` (~40 行)、`iNES_ExecPower` (~20 行)、`iNesSave/SaveAs` (~60 行)、`bmap[]` (~250 行) 无法迁移（含函数指针/生命周期钩子）。实际可迁移的是 `iNESLoad` 和 `CheckHInfo` 中的纯解析逻辑。

### 保留的 C++ 代码

| 函数 | 行数 | 原因 |
|------|------|------|
| `bmap[]` | ~250 | 含 `MapperNN_Init` 函数指针 |
| `iNES_Init()` | ~50 | 调用 `bmap[].init()` |
| `iNESGI()` | ~40 | 生命周期钩子 |
| `iNES_ExecPower()` | ~20 | 调用 `iNESCart.Power()` |
| `iNesSave/SaveAs` | ~60 | 文件写入 |
| `iNESLoad()` 残余 | ~150 | 内存分配 + mapper 初始化 + cart 创建 |
| 其他 | ~30 | 全局变量、forwarders |
